## Debugging steps
1. Customer saw a paywall instead of Theme Options in the BuddyBoss Theme settings and asked if the options are now Pro only.
2. Asked for admin access and the license key to check the site.
3. Checked the license status in the admin: the license had expired and was not connected.

## Solution
Theme Options are not Pro only. They need an active BuddyBoss Theme license connected in the admin. Renew the subscription and connect the license key, then Theme Options become available again.
Root cause: the license had expired, so the theme showed the locked screen instead of Theme Options.

## Customer note
Said it makes sense and got it, noting the last invoice showed a yearly purchase.
