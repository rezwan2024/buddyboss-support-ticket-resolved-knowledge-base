## Debugging steps
1. Checked the customer's screenshot: course sidebar Start buttons were already green, only the lesson navigation buttons (previous, complete and continue) at the bottom of the lesson were blue.
2. Ruled out: a separate course color setting. BuddyBoss Courses has no color options of its own.
3. Confirmed the course buttons take their colors from Primary Color and Button color in BuddyBoss Theme Options, so the blue comes from the theme color settings.

## Solution
Set Primary Color and Button color in BuddyBoss > Theme Options to the wanted color, keeping in mind this also changes other parts of the site that use those colors.
To change only the course buttons, add a small custom CSS snippet that sets the background color of the lesson navigation buttons to the wanted hex color.
Root cause: BuddyBoss Courses buttons inherit the theme Primary Color and Button color settings and have no separate color setting.
