## Debugging steps
1. Confirmed the critical error on most pages while the newsfeed and members pages still loaded.
2. Checked the fatal error on the site directly with admin access instead of waiting for the debug log.
3. Traced the error to the Sharing add-on's Yoast SEO compatibility code, which looks for a Yoast component that current Yoast versions no longer include.
4. Reproduced the same error on a clean test site with Sharing and current Yoast SEO, confirming an add-on bug.

## Solution
Workaround: deactivate the BuddyBoss Sharing plugin. Yoast SEO can stay active, and only Sharing features are unavailable.
Permanent fix: update BuddyBoss Sharing to 2.1.2 or later, then reactivate it.
Root cause: the Sharing add-on's Yoast SEO compatibility step called a Yoast component removed in current Yoast versions, which caused a fatal error.
