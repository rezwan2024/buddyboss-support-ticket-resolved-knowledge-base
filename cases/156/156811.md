## Debugging steps
1. Compared the activations in the BuddyBoss account with the real installs: more activations than sites, with the root domain listed next to each subfolder install.
2. Ruled out: subdomain installs, which were never affected since both forms of the address are the same.
3. Confirmed each subfolder is a separate WordPress install with its own wp-config.php and database, so no misconfiguration on the site.
4. Found manual activation sends the full subfolder URL, but the later automatic license check sends the root domain, which creates a second activation and fills the slot limit.
5. Ruled out: removing the extra activations and reactivating, which only helped for about a week.

## Solution
Update to BuddyBoss Platform 3.5.1 and BuddyBoss Theme 2.22.1, then remove the extra root domain activations in the BuddyBoss account and reactivate the license on the subfolder site.
Workaround until updated: remove the extra activation in the account and reactivate manually to get updates back.
Root cause: the automatic license check reported the root domain instead of the subfolder URL, creating duplicate activations.
