## Debugging steps
1. Tested on a site with BuddyBoss Membership active: no built-in option to show or hide menu items by membership plan.
2. Ruled out: role-based menu rules carrying over to membership plans; they stay role based.

## Solution
Workaround: use a third-party menu visibility plugin that adds rules per item under Appearance > Menus and supports custom conditions, so a rule can check the membership plan. Test on staging for each plan first. A single membership-based setting can be sent as a feature request.
Root cause: BuddyBoss Membership has no menu visibility integration yet.

## Customer note
No reply after the workaround was given; ticket closed for inactivity.
