## Debugging steps
1. Customer reported that photo uploads from phones fail some of the time while other uploads work.
2. Checked the server PHP upload limits on the same site and found them low, which also blocked video uploads.

## Solution
No separate photo fix was given. The same step was advised for the site: ask the host to raise upload_max_filesize, post_max_size, memory_limit, max_execution_time and max_input_time so that full-size phone photos fit within the limits.
Root cause: not confirmed. Most likely server PHP upload and memory limits that large mobile photos sometimes go over.
