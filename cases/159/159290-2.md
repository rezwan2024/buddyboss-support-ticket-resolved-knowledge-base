## Debugging steps
1. Checked Dashboard > Users, Apps Installed column: most members showed None, only a few showed a device.
2. Opened a member's profile Devices tab: no devices found for members showing None.
3. Ruled out: sending itself; pushes reached members with a registered device once the APNs key was valid.
4. Explained that group post pushes seemed to work sometimes because only the few registered members in the group received them.

## Solution
Members who use the app but show None must delete the app, install it again, log in and allow notifications. This creates a new device token and the member then shows a device count (for example 1 Device) under Apps Installed.
Use Dashboard > Users, sort by Apps Installed, to see who can receive push; the profile Devices tab shows each device token and last activity. Ask members by post or email to reinstall, since push cannot reach members showing None.
Root cause: those members had no valid device token registered (expired or never registered), and push only goes to registered devices; the in-app notification list works separately.
