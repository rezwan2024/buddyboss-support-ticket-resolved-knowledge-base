## Debugging steps
1. Checked Users > Pending Signups for the member. Ruled out: account waiting for activation, the member was not listed there.
2. Checked the member's account from the profile opened in the activity feed. The account was created and already active.
3. Found the first and last name were saved in reverse order with a different spelling, so searching the expected name returned nothing in All Users and the Members directory.
4. Searched by the saved last name and saved spelling. The member showed in both All Users and the Members directory.
5. Ruled out: Better Messages or another plugin conflict, registration worked as expected.

## Solution
No fix needed. The account was created and active. Search by the name exactly as saved on the profile, and correct the name by editing the profile so searches find it.
A new member only appears in the Members directory after visiting the site once after registering, which is why it was missing at first.
Root cause: the member's name was saved in a different order and spelling than expected, so searches did not match.
