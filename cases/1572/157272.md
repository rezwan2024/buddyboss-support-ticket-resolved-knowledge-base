## Debugging steps
1. Checked the push notification log in the app settings: iOS deliveries failed with an APNs device token error since the first push.
2. Checked Build History, then requested a new iOS and Android build; both completed, so the build no longer failed.
3. Ruled out: missing Firebase project; the project and app config files were in place, the Apple side of Firebase was the problem.

## Solution
Create a new APNs Auth Key (.p8) in the Apple Developer account and upload it in Firebase Console > Project settings > Cloud Messaging > Apple app configuration. Install the new build on the iPhone and send a new push notification.
Root cause: the APNs key in Firebase was missing or invalid, so Firebase could not deliver to iOS devices.
