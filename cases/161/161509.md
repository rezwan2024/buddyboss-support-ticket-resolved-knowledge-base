## Debugging steps
1. Customer asked before building the app whether Next Gen supports PMPro, since the docs only mention MemberPress and BuddyBoss Memberships.
2. Confirmed the app is not limited to one membership plugin: it follows the membership level and access the plugin sets on the site.
3. Ruled out: how the level was given. Paid, activation code or invitation give the same app access, because the app reads the same PMPro level.

## Solution
Keep PMPro. Levels, access rules and expiry are set by PMPro on the site, and the app follows them. WooCommerce Subscriptions can keep handling payments on the website.
For purchases made inside the app, Apple and Google need their own in-app purchase systems: create in-app purchase products in the app and map each one to the matching PMPro level.
Root cause: Misunderstanding. The docs list only some membership plugins, but the app works with the membership plugin used on the site.
