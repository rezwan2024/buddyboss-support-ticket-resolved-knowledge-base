## Debugging steps
1. Checked the failed build in AppCenter; the customer saw no error code or details.
2. Sent a build with dark mode disabled; it succeeded, so dark mode was the trigger.
3. Escalated to the developers; found the App plugin sent the whole Next Gen build payload in one upload with a fixed 45 second timeout.
4. On the slow host the upload was cut off part way, so the last files (the dark mode ones) were saved empty and the build failed deep in the pipeline.
5. Found Cloudflare was challenging the build server callbacks that fetch assets from the site.

## Solution
Update the BuddyBoss App plugin to the latest version (fix released, AppCenter side fixed automatically).
In Cloudflare, Security > WAF > Custom rules, add a rule matching URI path starts with /wp-json/ OR /wp-content/uploads/ OR user agent contains BuddyBossBot, action Skip (Super Bot Fight Mode, Browser Integrity Check, rate limiting and managed rules). Purge the Cloudflare cache and send a new build with dark mode enabled.
Root cause: the single build upload with a fixed timeout was truncated on the host, so the dark mode files arrived empty.
