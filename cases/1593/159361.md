## Debugging steps
1. Tried to reproduce on a clean local install. Ruled out: BuddyBoss core bug, the password change worked there.
2. Created a new test user on the affected site and changed the password from the profile Account Settings page. Reproduced: success email sent, password not changed.
3. Ruled out: WordPress core password handling, the lost password reset on wp-login.php worked.
4. Found site-specific custom plugins hooking into signup, registration and password functions. Disabled them temporarily and the password change worked.

## Solution
Disable the custom or third-party plugins that hook into signup, registration or password update, then re-enable one by one to find the conflicting one. Have the site developer fix that plugin's code.
Root cause: a site-specific custom plugin hooked into the signup or password update process and stopped the new password from being saved, while the change email still went out.
