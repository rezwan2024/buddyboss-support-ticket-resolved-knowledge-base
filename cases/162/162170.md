## Debugging steps
1. Checked the app menu settings: Notifications and Messages had different icons saved.
2. Ruled out: site and app cache. Clearing caches did not help.
3. Set up the same header bar config on a test app: both icons showed correctly, so it did not reproduce.
4. Asked to update the BuddyBoss App plugin to the latest version, clear the App API cache, App transient cache, caching plugin and server cache, then remove both header icons, make a new build, and add the icons back one at a time.

## Solution
Update the BuddyBoss App plugin, clear all caches, and create a new app build. The new build showed the correct separate icons.
Root cause: the old app build was rendering stale header icon data. A new build made after the plugin update fixed it.
