## Debugging steps
1. Compared the same quiz completed on the web and in the app: web sends the custom admin email with category scores, app sends LearnDash's default subject and body.
2. Traced the app email sender with an SMTP logging plugin to the App plugin LearnDash quiz complete REST handler (QuizComplete.php).
3. Ruled out: LearnDash settings. Admin and user notifications, quiz statistics and the custom admin template with $categories were all correctly set.
4. Ruled out: default admin template lacking $categories. The saved Admin Notifications template already had $categories and a custom subject.
5. Escalated to the app developers, who confirmed the app completion path does not read the saved Quiz Email Settings.

## Solution
Update the BuddyBoss App plugin to v3.2.7 or later. App quiz completions then send the configured LearnDash Quiz Email Settings template, including the custom subject and $categories.
Root cause: the App plugin quiz completion endpoint sent LearnDash's default notification instead of using the saved Quiz Email Settings template and category data.

## Customer note
Said everything is working after the update, and suggested the app quiz results page show the same message as the web version.
