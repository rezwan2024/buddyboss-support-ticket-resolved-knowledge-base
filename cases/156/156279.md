## Debugging steps
1. Reviewed the error screenshots and the stack trace shown when LearnDash is activated.
2. Stack trace pointed to the LearnDash custom label class (includes/class-ld-custom-label.php, line 233), called while LearnDash registers its widgets.
3. Found that mb_strtolower() is undefined because the PHP mbstring extension is not enabled on the server.
4. Ruled out: BuddyBoss conflict. No BuddyBoss plugin was active, and WordPress core loads normally because it has its own fallbacks for mbstring.

## Solution
Ask the hosting provider to enable the mbstring PHP extension for the active PHP version (in cPanel it is usually a checkbox in the PHP Selector). Once mbstring is enabled, LearnDash activates without the fatal error.
Root cause: the mbstring PHP extension was disabled on the server, often switched off after a PHP version change, and LearnDash requires it.
