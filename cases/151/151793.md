## Debugging steps
1. Confirmed the truncation happens in the backend, in the view report modal of moderation, not on the frontend.
2. Inspected the modal: the CSS class bb-admin-view-report-modal__category-desc uses white-space: nowrap with overflow hidden and text-overflow ellipsis, so long reporter text is cut to one line.
3. Reproduced on a test site with a long report description and escalated as a bug.

## Solution
Update BuddyBoss Platform and BuddyBoss Theme to the latest versions, where the fix for the truncated report description was released.
Workaround before updating: add this CSS to the admin area with a code snippet plugin.
```css
.bb-admin-view-report-modal__category-desc {
    white-space: normal;
    overflow: visible;
    text-overflow: clip;
}
```
Root cause: the admin report modal style forced the report description onto one line (white-space: nowrap) and hid the overflow.

## Customer note
No reply after being told the fix was released; last reply said setting white-space: normal on the CSS class makes it work.
