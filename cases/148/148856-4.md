## Debugging steps
1. The customer asked what "Add New Button" and "Option button" do in the Header Bar admin, and why only the icon can be edited.
2. After a new build, only the create post button showed in the header. It was blue in the app but black in the header bar admin settings.
3. The support agent said they would check the color settings. The ticket gives no result for that check.

## Solution
Add New Button only adds a new icon or changes an icon. The option button block is dynamic and changes with the app page content, so its buttons depend on where the user is in the app. Only a limited number of available app menus can be added to the header bar. The color difference was not resolved in the ticket.
Root cause: For the questions, this is how the header bar is designed to work. The cause of the color difference was not found.

Said these options should be in style settings because there are no real editable menu functions there. The color question got no answer.
