## Debugging steps
1. Checked BuddyBoss > Theme Options > Custom Codes: Tracking Code option switched on and the full Google Analytics snippet pasted in the Tracking Code field.
2. Cleared caching plugin and CDN cache, then tested in a private browser window before running Google's check again.
3. Fallback if still not detected: add the same snippet with a code snippet plugin such as WPCode, set to run in the site header.

## Solution
Purge the Cloudflare (CDN) cache after adding the tracking code in Theme Options > Custom Codes, then run Google's check again. Google detected the code right after the purge.
Root cause: Cloudflare kept serving cached pages without the new tracking code, so Google could not find it.
