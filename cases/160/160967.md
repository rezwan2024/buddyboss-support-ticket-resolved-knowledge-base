## Debugging steps
1. Checked the fatal error screenshot: the call stack starts in the BuddyBoss Theme admin-init.php, not in Platform.
2. The old Theme calls checkLicenseStatus(), which was removed when the license manager was rebuilt in Platform 3.5.1.
3. Ruled out: corrupted Platform files. No need to delete or reupload Platform.
4. Theme update notice was missing in the WordPress dashboard because the license key was not connected on that site.

## Solution
Update BuddyBoss Theme to the latest version first, then update BuddyBoss Platform to 3.6.0. If the site is already down, download buddyboss-theme.zip from the BuddyBoss account Downloads and upload it in Appearance, Themes, Add New, Upload Theme, then pick Replace current with uploaded (or use recovery mode or replace the buddyboss-theme folder by file access). Child theme and settings stay as they are.
Root cause: An older BuddyBoss Theme calls a license method that newer Platform versions no longer have.
