## Debugging steps
1. Opened a member profile, Documents tab, went into a folder and clicked Move on a file.
2. Checked the browser console: TypeError reading 'find' in openDocumentMove in buddypress-media.min.js.
3. Confirmed it as a known Platform bug and escalated to development.

## Solution
Update BuddyBoss Platform to v3.6.0 or later (released together with BuddyBoss Addons v1.2.1), where the bug is fixed.
Root cause: Platform bug in the openDocumentMove script, which read an undefined object when moving a document from inside a profile folder.
