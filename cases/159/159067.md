## Debugging steps
1. Reproduced from the customer video: in the app Edit Profile screen, each profile field description or note appears twice.
2. Matched the symptom to a known App bug fixed in app version 3.2.0 (released 21 September).
3. Asked the customer to update the BuddyBoss App plugin and BuddyBoss Platform plugin to the latest versions.
4. Asked for a new app build made after the 3.2.0 release and uploaded to the stores.

## Solution
Update the BuddyBoss App plugin and BuddyBoss Platform to the latest versions, then create a new app build (app version 3.2.0 or later) and submit it to Apple and Google. After the new release, each description shows only once in Edit Profile.
Root cause: Next Gen app rendering bug that duplicated profile field descriptions, fixed in app version 3.2.0.

## Customer note
Confirmed the issues were resolved after updating to the new app release and asked to close the ticket.
