## Debugging steps
1. Checked the customer's screenshot of the white "Like this:" bar under the post.
2. Ruled out: BuddyBoss Theme color settings and custom CSS. The bar is not a BuddyBoss element.
3. Found the bar is the Jetpack Likes feature, loaded in an iframe served from an external domain, so site CSS and theme colors cannot style it.
4. Ruled out: a Jetpack setting for a dark Likes background. Jetpack has no such option.

## Solution
No styling fix is possible from the site. Either turn Likes off in Jetpack > Settings > Sharing (Likes toggle), or per post in the post editor settings, or keep the white Likes block as it is.
Root cause: the Jetpack Likes widget is an iframe from another domain, so the theme's dark colors and custom CSS cannot reach it.
