## Debugging steps
1. Checked the LearnDash course API endpoints (courses list, course details): all return 200 with complete data. Other app screens such as profiles and activity work.
2. Ruled out: API CDN, API caching, REST cache, page cache and object cache, all disabled or purged with no change.
3. Ruled out: course thumbnail image format, AVIF and PNG/JPEG courses fail the same way.
4. Ruled out: LearnDash 5.x requirement. Next Gen does not list LearnDash 5.x as required, so 4.25.6 should work.
5. Noted a PHP warning from RestCDN::rewrite_url on every course request, even with API CDN disabled. Open the course API response in a browser and check that it starts directly with JSON and no PHP warning text.

## Solution
No confirmed fix, the customer stopped replying. Recommended steps: update LearnDash, BuddyBoss App and the other plugins to the latest versions, then make a new Next Gen build and test Courses. If it still fails, deactivate caching and other plugins, keeping only Platform, Platform Pro, BuddyBoss App, LearnDash and the BuddyBoss LearnDash plugin, and build again. Also test a simple course with one lesson and no media, another user and another device.
Root cause: not confirmed. Most likely the PHP warning printed into the course REST response, so the Next Gen app could not parse it even though the request returned 200.
