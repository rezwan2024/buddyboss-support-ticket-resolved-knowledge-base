## Debugging steps
1. Customer reported custom group meta fields stopped showing after the update to the 3.0 dashboard.
2. Confirmed the 3.0 admin was rebuilt in React, moving away from the older meta field approach, so fields added by other plugins do not render on the new admin screens yet.
3. Confirmed this is treated as a bug, with fixes in progress per plugin.

## Solution
Known bug in 3.0, no fix in this ticket. Open a separate ticket with the plugin name and the exact group fields that disappeared so it is linked to the existing development work for that plugin.
Root cause: the 3.0 React-based admin does not yet render group meta fields registered by other plugins through the older meta field approach.
