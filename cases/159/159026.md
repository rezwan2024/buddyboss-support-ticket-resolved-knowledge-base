## Debugging steps
1. Checked the SMTP plugin log: the SMTP test email and WordPress system emails were sent, WooCommerce order emails and a GamiPress notification failed.
2. Found the WooCommerce From address did not match the mailbox the SMTP plugin connects with, so the mail host could reject those emails.
3. Set WooCommerce > Settings > Emails From address to the SMTP mailbox and tested with a test order and Resend new order notification. Order emails still failed.
4. Ruled out: SMTP connection details, since other emails pass through the same host connection.
5. The SMTP plugin log does not show the error reason for failed emails, so the exact cause could not be read from it.

## Solution
First make the WooCommerce (and GamiPress) From address match the SMTP mailbox. If order emails still fail, deactivate the current SMTP plugin, install FluentSMTP, add an "Other SMTP" connection with the same host details (port 465, SSL, same mailbox as From email), resend the new order notification and read the exact error in FluentSMTP Email Logs.
Only one SMTP plugin should be active at a time.
Root cause: not confirmed; WooCommerce builds its emails with its own headers and attachments, and something in those emails was rejected by the mail host.
