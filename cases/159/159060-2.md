## Debugging steps
1. Read the Play Console warning: Google requires Play Billing Library 8.0.0 or later.
2. Confirmed the Billing Library 8 update shipped in BuddyBoss App 3.1.5 and the latest Android build was generated on Core App Version 3.2.4, so it already includes it.
3. Asked the customer to release the new build to Production; the warning stayed after full rollout.
4. Ruled out: the live Production build, which already meets the requirement.

## Solution
Check Test and release in Play Console for an older app bundle still active on a testing track (internal or closed testing), because Google checks every active bundle. Release the new build to that track or deactivate the old release, then allow Google some time to re-check.
Root cause: likely an older bundle built before BuddyBoss App 3.1.5 still active on a testing track.

## Customer note
Said the warning remained after the new build went live; no reply after the testing track advice.
