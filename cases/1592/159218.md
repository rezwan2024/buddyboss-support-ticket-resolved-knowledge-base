## Debugging steps
1. Reproduced on the customer's app: tapping the blog post image or text in the Activity Feed shows the top loading bar but the post does not open.
2. Ruled out: app version. The same version on a test site opened blog posts normally.
3. Asked to disable optimization, security and cache plugins in case one restricts REST API loading. Not confirmed.
4. Retested on the app: tapping the post link opens the blog, tapping the post image does not.

## Solution
Tap the blog post link or title in the Activity Feed instead of the post image. This is a workaround; the customer did not confirm it and the ticket closed for inactivity.
If it still fails, disable optimization, security and cache plugins and retest, since one may block REST API requests.
Root cause: in the app Activity Feed blog preview, only the post link opens the blog; tapping the image does not.
