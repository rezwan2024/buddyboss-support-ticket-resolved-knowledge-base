## Debugging steps
1. Customer scanned the test build QR code with the phone, downloaded the APK and got the parsing error on install, several times.
2. Noted the download started very slow and then sped up, a sign of an incomplete or corrupted transfer.
3. Downloading the same build directly on the phone from the app build section in WP admin installed fine.
4. Ruled out: the build itself. Support scanned the QR code from the site dashboard and the build downloaded and opened without error.

## Solution
Download the test build again, or open the build section in WP admin on the phone and download the APK directly. A new test build later installed normally through the QR code too.
Root cause: a temporary download glitch left an incomplete APK file, not a broken build.

## Customer note
Said a new test build worked as before and it was likely a temporary glitch.
