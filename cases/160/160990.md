## Debugging steps
1. Checked the BuddyBoss Platform public GitHub repository: the reported Platform version was published there by the development team the same day.
2. Confirmed the Platform Pro, Theme and Addons notices belong to the same release, and internal development sites showed the same update notices.
3. Ruled out: a fake update. The release went out before the release notes page was updated, so the versions were missing from the notes for a short time.

## Solution
Confirm the updates are official and share the Platform changelog from the GitHub releases page (github.com/buddyboss/buddyboss-platform/releases). Platform releases appear there first, so the version in the dashboard can be matched against that list. The release notes page is updated shortly after.
For extra assurance, apply updates on a staging copy first with a fresh backup of the live site, and run a file change monitoring or malware scanning tool on staging to review which files changed. Requests for published checksums go to the product team.
Root cause: the release was published before the official release notes page was updated.

Thanked the team, said the release notes now show, and asked for a way to check update packages, such as checksums.
