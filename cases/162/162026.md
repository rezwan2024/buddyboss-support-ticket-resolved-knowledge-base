## Debugging steps
1. Reproduced: searching by Last Name in the Members Directory Search Filters panel did not refresh the results until the page was reloaded several times.
2. Checked that member first and last names are stored in the matching First Name and Last Name profile fields, since the filters search per profile field.
3. Purged the LiteSpeed Cache: the search worked again, but the issue came back after a while, so cached directory pages were being served.
4. Ruled out: "no members were found" after the change was caused by old filters still active in the Search Filters panel, not by the fix.

## Solution
Exclude the Members Directory page from page caching: LiteSpeed Cache > Cache > Excludes, add the Members Directory URL to Do Not Cache URIs, save, then purge all cache and test again.
Clear the Search Filters panel before a new search, as it keeps the last selected filters and can make members look missing.
Root cause: LiteSpeed Cache served a cached copy of the Members Directory page instead of fresh search results.
