## Debugging steps
1. Asked for a screen recording of the flow: three-dot menu on a document, click Move, no dialog appears.
2. Ruled out: browser issue, it happens on the latest Chrome.
3. Ruled out: JavaScript errors, the browser console shows nothing when Move is clicked.
4. Reproduced and matched to a known Platform bug, escalated to development.

## Solution
Update BuddyBoss Platform to 3.6.0 or later and BuddyBoss Addons to 1.2.1 or later. No workaround was given before the release.
Root cause: Platform bug where the Move action in the document menu did not open the move dialog for the document owner.

## Customer note
No reply after the fix release was announced; fix released in Platform 3.6.0.
