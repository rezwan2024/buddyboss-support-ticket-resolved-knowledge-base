## Debugging steps
1. Reset License Settings under BuddyBoss > License Activation > Troubleshooting, then activated the license again with key and account email. The notice stayed.
2. Checked the license on the BuddyBoss account side: it was connected and active for the site.
3. Ruled out: site cache. Purging host cache, the host optimizer plugin cache, the optimization plugin CSS and JS cache and the CDN cache did not remove the notice.
4. Checked for real feature locks in the dashboard and frontend: none reported, only the add-on activation notice and the license warning email.
5. Escalated to the development team with server file access to inspect the site.

## Solution
The development team fixed it after inspecting the site with server access; the add-on license notice went away and the add-ons showed as activated. The exact change was not shared in the ticket.
Root cause: the add-on license status stored on the site was out of sync with the active license on the account, not a missing or expired license.

## Customer note
Confirmed the notice was gone and thanked the team for the help.
