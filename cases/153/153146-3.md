## Debugging steps
1. Customer made a first BuddyBoss App build on Next Gen (App Core 3.2.4) for a site whose courses are all in Tutor LMS Pro.
2. The Courses screen in the tab bar showed "This screen type is not yet implemented" (object type: courses_all).
3. The Next Gen announcement says Next Gen does not support Tutor LMS yet, while the React Native app does.

## Solution
No support answer in this ticket. Known limit: Next Gen has no native Tutor LMS course screens yet. The React Native app supports Tutor LMS. As a stopgap, the customer added the Tutor LMS enrolled courses page to the tab bar as a Custom Link.
Root cause: Tutor LMS course screens are not yet supported in the Next Gen app.

## Customer note
Asked when Next Gen will support Tutor LMS, whether they can build on the React Native app for now, and whether a Custom Link to the courses page keeps members logged in. No answer in this ticket.
