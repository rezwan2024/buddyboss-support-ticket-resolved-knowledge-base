## Debugging steps
1. Tested both on a test site with the same Platform version: the daily and weekly digest template Preview (BuddyBoss > Emails > three dots > Preview) loads and shows the layout with placeholders, not real notifications.
2. Ruled out: a product bug for the empty test digest. Send Test Digest builds a real digest from notifications waiting for the admin's own account, so it is empty when nothing is queued.
3. The blank Preview page did not happen on the test site, so it points to something on the customer's site; asked for temporary admin access to check the preview page and error logs.

## Solution
For the test digest: on the frontend open your own Notification Settings and set Email digest to Daily or Weekly, save, then from a second account mention the admin or reply to its post, then click Send Test Digest on the Email Digest tab. Activity before switching to digest was already sent as normal emails and will not appear.
For the blank Preview: not resolved in this ticket; needs a site check (error logs, plugin or theme conflict).
Root cause: test digest only includes notifications queued for the admin account after it opted in to digest; the blank preview is site specific and was not found.

Said the preview does not work and the test email cannot be sent; no reply after access was requested.
