## Debugging steps
1. Confirmed no changes were made to the site or app by support. Testing was done on a separate test site and app.
2. Found the header icons had been removed and added back in BuddyBoss App > Menus while troubleshooting.
3. Newly added icons start with the default icon style, so the earlier custom color was replaced.

## Solution
Go to BuddyBoss App > Menus > Header Bar, click each header icon, and set the color again in its icon settings. Use the color code from your own branding, since the old custom value is not stored anywhere.
Root cause: re-adding a header icon resets it to the default icon style and color.

## Customer note
Said they managed to get the original colors back and thanked the team, but asked for the old default orange color palette.
