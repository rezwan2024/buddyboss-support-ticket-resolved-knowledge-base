## Debugging steps
1. Checked the customer screenshots: each notification shows the avatar and time, but the text line is empty. Tapping opens only Mark as read and Delete.
2. Ruled out: device problem, same result on iPhone and iPad.
3. Ruled out: outdated BuddyBoss App plugin, it was already on the latest version.
4. Checked the latest iOS release build of the app: notifications show their full text there, and the layout differs from the customer's screenshot.
5. Asked for the live store app link to compare the version members use with the latest build.

## Solution
First advice: update BuddyBoss Platform and the BuddyBoss App plugin, then create new iOS and Android release builds and publish them, since an app build older than Platform 3.5.0 may not get the notification text.
Not finished: the latest build showed full notification text, so the next step was to compare it with the live store app. The ticket closed with no reply.
Root cause: not confirmed. Most likely the live store app is an older build than the latest build created in BuddyBoss App.
