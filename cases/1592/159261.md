## Debugging steps
1. Collected screenshots of the error from affected iOS users.
2. Asked for WP-Admin access and an affected user account to reproduce. The user account was not shared.
3. Tested the iOS app with a test account. The app worked and the error did not appear.
4. Ruled out: a site-side configuration problem, since the app worked against the same site.

## Solution
Generate a new iOS build from the latest App plugin and AppCenter, publish it, and ask the affected users to update and test again. The customer did not confirm the result before the ticket auto-closed.
Root cause: not confirmed. Most likely users were running an older build that did not match the current App plugin and site data.
