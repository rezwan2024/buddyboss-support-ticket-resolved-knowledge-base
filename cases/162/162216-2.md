## Debugging steps
1. Checkout failed after rolling Membership back to 1.14.1 and showed the BbmsStripeTaxIntegration fatal error.
2. Confirmed it as a known bug present since 1.14.1 and still in 1.14.2: the class is not shipped with the plugin, so every Stripe checkout render and submit fails.

## Solution
Update BuddyBoss Membership to 1.14.3, which ships the fix, then run a test checkout in Stripe test mode.
Workaround before the update: in a child theme, define a stub BbmsStripeTaxIntegration class wrapped in class_exists() that returns an empty tax code (only if Stripe Tax is not used). It steps aside once the fixed version is installed.
Root cause: Membership 1.14.1 and 1.14.2 reference the BbmsStripeTaxIntegration class without including it, fixed in 1.14.3.

## Customer note
Said checkout works with their own workaround and thanked the team; no reply after being told about 1.14.3.
