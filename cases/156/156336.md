## Debugging steps
1. Customer had BuddyBoss Platform Pro installed but the BuddyBoss Addons entry showed Not Installed in the dashboard.
2. Premium features such as pinned posts, polls, social login and emotion reactions could not be turned on.
3. Ruled out: a missing module inside the Platform Pro ZIP. The add-on features now ship in a separate plugin.

## Solution
BuddyBoss Addons is a new, separate plugin. Download it from the BuddyBoss account downloads area, upload and activate it under Plugins > Add New > Upload Plugin, then enable the features in BuddyBoss settings.
Root cause: the features moved to a separate BuddyBoss Addons plugin that was not installed; Platform Pro alone does not include it.
