## Debugging steps
1. Checked the profile type shortcode in the BuddyBoss Platform code: it has no sorting option of its own.
2. Confirmed it falls back to the default member list order, Recently Active (most recently active member first).
3. Ruled out: registration date and profile modified date as the sort field.

## Solution
The profile type shortcode (for example `[profile type="student"]`) uses the default member order, Recently Active, sorted by each member's last activity time, newest first.
Last activity is updated each time a logged-in member loads a page on the site, and when they post or comment through the BuddyBoss App. In practice it shows when the member was last on the site while logged in.
Root cause: Not a bug. The shortcode has no sort option and inherits the member directory default of last activity time.
