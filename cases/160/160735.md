## Debugging steps
1. Reproduced the member blog editor on a test site with BuddyBoss Theme 2.22.0, Platform 3.6.0 and Member Blogging 1.0.0.
2. Ruled out: Member Blogging has no color setting of its own for the Preview button.
3. Ruled out: the Button Text Color and Secondary Button Text Color in Theme Options do not change the Preview button.
4. Found the Preview button text uses the Headings Color and its background uses the Secondary Button Background Color (Regular) in BuddyBoss > Theme Options > Colors.
5. Same text and background color appears when both values are set to the same brand color.

## Solution
Check Headings Color and Secondary Button Background Color in BuddyBoss > Theme Options > Colors. Changing either is global (headings site-wide, and Join Group, Follow, Connect, profile and group header and LearnDash buttons), so a CSS rule aimed only at the Preview button, added with a code snippet plugin or custom CSS, is the safe workaround. The site's own developers made the final change.
Root cause: Preview button text inherits the Headings Color, which matched the Secondary Button Background Color.
