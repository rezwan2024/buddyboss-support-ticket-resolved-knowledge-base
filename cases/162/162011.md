## Debugging steps
1. Switched Site Layout from ReadyLaunch to WordPress Theme and re-saved permalinks: images displayed, including older broken ones. Switching back to ReadyLaunch broke them again.
2. Opened an image preview URL directly: it returned the ReadyLaunch page layout instead of the image file.
3. Ruled out: a general ReadyLaunch issue, could not reproduce on a clean site with default settings.
4. Checked BuddyBoss > ReadyLaunch > Pages: the Blog page was enabled, which made ReadyLaunch render its layout on media, document and video preview URLs.

## Solution
Add this PHP snippet with a code snippet plugin (run everywhere) so ReadyLaunch skips the preview URLs. Workaround while keeping the ReadyLaunch Blog page on; turning the Blog page off also avoids it.
```php
add_filter( 'bb_is_readylaunch_enabled_for_page', function ( $enabled ) {
	if ( ! did_action( 'wp' ) || ! ( $GLOBALS['wp_query'] ?? null ) instanceof WP_Query ) {
		return $enabled;
	}
	$preview_vars = array( 'bb-media-preview', 'media-attachment-id', 'bb-document-preview', 'bb-document-player', 'document-attachment-id', 'bb-video-preview', 'bb-video-thumb-preview', 'video-attachment-id' );
	foreach ( $preview_vars as $var ) {
		if ( get_query_var( $var ) ) {
			return false;
		}
	}
	return $enabled;
}, 99 );
```
Root cause: with the ReadyLaunch Blog page enabled, ReadyLaunch takes over the BuddyBoss media, document and video preview URLs and serves its HTML layout instead of the file.
