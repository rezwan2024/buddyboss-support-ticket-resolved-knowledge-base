## Debugging steps
1. Asked the customer to recheck from an administrator account; the pin option was still missing.
2. Logged in to the community subsite and opened BuddyBoss > Settings > Activity.
3. Found the Pinned Post setting still present but shown as locked with a plan badge instead of a toggle.
4. Checked the licence panel: the site was still connected with a legacy licence (one of one activations used) and the BuddyBoss Addon plugin was not installed, so the Platform could not match the licence to a plan.

## Solution
From a full administrator account: download the BuddyBoss Addon plugin (and the latest BuddyBoss Theme if behind) from the BuddyBoss account, disconnect the old licence in the dashboard, install and activate the Addon plugin, connect the current licence from the BuddyBoss account, then switch Pinned Post on under BuddyBoss > Settings > Activity. The pin option returns in the post three dots menu.
Root cause: after the plan reorganisation, plan features stay locked until the BuddyBoss Addon plugin is active and a current licence replaces the legacy one.
