## Debugging steps
1. Checked the code behind each warning: the forums line runs when a forum edit capability check is called without a forum ID; the Elementor line runs when Elementor cannot find a page or template.
2. Ruled out: a damaged update. The BuddyBoss file matched the current release, so a reinstall would not help.
3. Checked Site Health: WordPress debug mode was off, so the warnings were printed by the host's PHP display_errors setting.

## Solution
Ask the host to turn off PHP display_errors for the site, keeping PHP error logging on. To still review warnings, use the server error log or set WP_DEBUG true, WP_DEBUG_LOG true and WP_DEBUG_DISPLAY false in wp-config.php, then turn WP_DEBUG off again when done.
These are non-fatal warnings and need no other action.
Root cause: PHP display_errors was on at the hosting level, so harmless warnings printed on every page.

## Customer note
Said the host made the change, the warnings no longer show, and thanked the team.
