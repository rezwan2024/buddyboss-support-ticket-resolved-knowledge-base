1. Customer report: on a group activity post, open the comment box and click Cancel; the form class changes to not-initialized but the form stays visible, with no console errors.
2. Ruled out by customer: turning off their own custom snippets did not change the behaviour.
3. Tested on a clean install of Platform 3.4.4 with ReadyLaunch: Cancel closed the comment form as expected. Not reproduced.
4. Asked for a staging copy and the custom snippets that touch the activity comment scripts.
