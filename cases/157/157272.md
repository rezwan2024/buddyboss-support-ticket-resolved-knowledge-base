## Debugging steps
1. Checked the push notification log in the app settings: delivery failures with an APNs device token error and with SenderId mismatch.
2. Ruled out: a new Firebase project alone. Customer recreated the Firebase setup but devices still ran an old build.
3. Checked Firebase Cloud Messaging Apple app configuration for a valid APNs key.
4. Requested new iOS and Android builds and installed them on test devices.

## Solution
Create a new APNs auth key (.p8) in the Apple Developer account and upload it in Firebase Console > Project settings > Cloud Messaging > Apple app configuration. Reconfigure Firebase for push as per the docs, then request new iOS and Android builds and install them, since old builds keep the old sender config.
Root cause: Firebase push config did not match the build on the devices (old sender ID) and the APNs key in Firebase was missing or invalid.
