## Debugging steps
1. Searched BuddyBoss App > Translations by text and by Source Text ID for ld_mark_as_incomplete. Not found (note the key starts with a lowercase L, not ID).
2. Downloaded the CSV as a backup, clicked Re-import Strings and searched again. Still missing.
3. Ruled out: the quiz complete and incomplete strings. They only cover LearnDash quizzes, not the lesson buttons.
4. Reproduced on a clean test site: ld_mark_as_complete is listed, ld_mark_as_incomplete is not. Confirmed as a bug and escalated.

## Solution
Fixed by BuddyBoss: ld_mark_as_incomplete is now in BuddyBoss App > Translations next to ld_mark_as_complete, with a weekly string sync for new releases. Search "mark as", set the wording, Save Changes.
Create a new app build and install it, the changed wording did not show in the existing test build until rebuilt.
Root cause: the ld_mark_as_incomplete string was missing from the Next Gen app string set.
