## Debugging steps
1. Tried to reproduce View as and the browser back button on current and older versions. Could not reproduce a real logout.
2. Found the back button reloads the WP Admin Users page while still viewing as the member, so WordPress shows a permission error. The session is not lost.
3. Ruled out: browser. The black top bar is the WordPress toolbar and shows the same in Firefox.
4. Checked why the toolbar and the Switch back to Admin link were missing: the admin profile option "Show toolbar when viewing site" was the likely cause.

## Solution
Do not use the browser back button in View as mode. Go back with Switch back to Admin in the black top bar, or with Back to Admin in the three-dot menu of the member's profile header.
If the black top bar is missing, turn on WP Admin > Users > Profile > Toolbar > "Show toolbar when viewing site" for the admin account. Opening View as in a new tab is not available and was logged as a feature request.
Root cause: View as switches the session to the member, so admin pages are blocked, and the toolbar holding the Switch back link was turned off.
