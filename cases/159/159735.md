## Debugging steps
1. Checked that the Tracking Code option is switched on under BuddyBoss > Theme Options > Custom Codes and that the full Google Analytics snippet, including the script tags, is pasted and saved.
2. Cleared the caching plugin and CDN cache, then tested the site in a private browser window before running Google's check again.
3. Fallback: add the same snippet with a code snippet plugin such as WPCode, set to run in the site header.

## Solution
Purge the CDN cache (Cloudflare in this case) after saving the tracking code in Theme Options, then run Google's tag check again.
Root cause: the CDN kept serving cached pages without the new tracking code, so Google could not see it.

## Customer note
Said it works after clearing the Cloudflare cache and asked to close the ticket.
