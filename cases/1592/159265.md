## Debugging steps
1. Checked the code behind each warning: the Forums line is a permission check called without a forum ID, the Elementor line runs when a page or template can no longer be found.
2. Ruled out: corrupted update, the Platform file matched the current release, so a reinstall would not help.
3. Ruled out: WordPress debug mode, Site Health showed WP_DEBUG off, so the warnings were printed by the server PHP display_errors setting.

## Solution
Ask the host to turn off PHP display_errors for the site and keep error logging on. To still review warnings, log them instead of showing them:
```php
define( 'WP_DEBUG', true );
define( 'WP_DEBUG_LOG', true );
define( 'WP_DEBUG_DISPLAY', false );
```
Turn WP_DEBUG off again after reviewing, since debug.log grows fast and is browser reachable. The warnings are not fatal and need no further action.
Root cause: server PHP displayed non-fatal warnings on the page instead of only logging them.
