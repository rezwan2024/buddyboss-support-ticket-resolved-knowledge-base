## Debugging steps
1. Tested poll voting on a development site with the latest Next Gen build on iOS: worked.
2. Ruled out: poll creation, it worked from the iOS app with an admin account; the issue was selecting options.
3. Customer pushed a new iOS build to TestFlight: voting on existing group polls still failed.
4. Created a new poll in a group and voted from the iOS app: worked.
5. Found that only older, still-open polls could not be voted on in the iOS app, while new polls in the same group worked.

## Solution
Workaround: create new polls and use them instead of the old ones. The old polls could not be fixed.
Root cause: the data of the old polls was corrupted, so the iOS app could not register votes on them.

## Customer note
Said they understood, thanked the team and asked to close the ticket.
