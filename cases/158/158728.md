## Debugging steps
1. Checked the customer's screenshot of the admin notice.
2. Found the same panel also says "Complete setup by activating your license", so the site was not picking up the Start license at all.
3. Asked the customer to check under Plugins whether the BuddyBoss Add-on plugin is installed and active.

## Solution
Install and activate the BuddyBoss Add-on plugin: download it from the BuddyBoss account, upload it under Plugins > Add New > Upload Plugin, activate it, then reload any wp-admin page and check that the warning is gone. If it stays, check the site directly with admin access.
Root cause: the Start license was not activated on the site, so the Launch/Scale activation warning kept showing.
