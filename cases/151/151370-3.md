## Debugging steps
1. Customer could generate an iOS release build but not a test build, and needed to test before going live.
2. Confirmed uploading to App Store Connect does not submit the app for review.

## Solution
Request a release build in BuddyBoss App > Build, then upload it from BuddyBoss App > Upload > Apple App Store. In App Store Connect add testers under Users and Access, then add them to the internal group in the TestFlight tab. Testers install the app with the TestFlight app. For later builds only the upload step is repeated.
Root cause: not a bug, TestFlight is the way to test a release build without submitting it for review.
