## Debugging steps
1. Generated fresh test builds for both the Classic and Next Gen app; downloaded videos still did not play in either.
2. Ruled out: server security blocking. The host checked firewall and ModSecurity logs, found no blocked BuddyBossBot requests, and allowlisted the user agent anyway.
3. Ruled out: Cloudflare proxy. Turning the proxy off and clearing the cache did not change anything.
4. Found that the videos still stream fine in the app and only offline downloads fail, and this began after the videos were moved from one Vimeo account to another with the same video IDs.

## Solution
Reset the Vimeo integration in the BuddyBoss App settings and connect it to the Vimeo account that now owns the videos. Then download the videos again in the app.
Root cause: Offline downloads use the connected Vimeo account's access. After the transfer, that account no longer owned the videos, so downloaded files would not play.

## Customer note
Said the problem is fixed after resetting the Vimeo integration and asked to close the ticket.
