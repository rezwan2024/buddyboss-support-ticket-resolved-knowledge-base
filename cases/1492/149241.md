## Debugging steps
1. Opened a user profile, Documents tab, went into a folder and tried to move a file.
2. Checked the browser console and found the TypeError in openDocumentMove from the media script.
3. Confirmed it as a known Platform bug in the document move code, not a site configuration issue, and escalated to development.

## Solution
Update BuddyBoss Platform to v3.6.0 or later (and BuddyBoss Add-ons to v1.2.1 or later), where the fix was released.
Root cause: Platform bug in the openDocumentMove script, which did not handle being opened from inside a profile document folder.
