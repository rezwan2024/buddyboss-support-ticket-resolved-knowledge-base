## Debugging steps
1. Asked for a written description of each issue, because the screen recording alone was not clear.
2. Ruled out: subscription. Both sites were on the same subscription.
3. Compared the BuddyBoss App plugin version on both sites: the site with the Next Gen option ran 3.2.8, the site without it ran 2.10.1.
4. Customer had updated Platform and Theme the same day, but no BuddyBoss App plugin update showed in the dashboard.

## Solution
Download the latest BuddyBoss App plugin from the BuddyBoss account and update it manually: Plugins > Add New > Upload Plugin, upload the ZIP and replace the current version. The Next Gen switch option needs the newer plugin version.
If the update notice does not show, the server may not reach the update API or WP-Cron may not be running the update check, so a manual update is the way forward.
Root cause: the site ran an old BuddyBoss App plugin (2.x) without the Next Gen switch, and its update notice did not appear in the dashboard.
