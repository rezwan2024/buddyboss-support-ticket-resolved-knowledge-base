## Debugging steps
1. Confirmed the lessons were created separately under BB Courses > Lessons, then the customer tried to connect them to a course.
2. Reproduced on a clean install: a lesson created on its own under BB Courses > Lessons cannot be linked to a course afterwards.
3. Ruled out: a site-specific fault. This is how BB Courses currently works, as lessons are only created from inside the course.

## Solution
Edit the course under BB Courses > Courses, open the Curriculum tab, click Add section, then inside the section click Add Lesson..., enter the title, use the edit icon to add content and click Publish beside it.
Workaround for lessons already built separately: copy their content into new lessons created from the Curriculum tab. An option to connect existing lessons to a course was passed to the development team as a feature request.
Root cause: BB Courses has no option to assign a standalone lesson to a course; lessons must be created from the course Curriculum tab.
