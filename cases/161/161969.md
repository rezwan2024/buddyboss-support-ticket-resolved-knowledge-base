## Debugging steps
1. Read the fatal error from the Recovery Mode email: E_ERROR, call to undefined function BuddyBossApp\wp_get_current_user(), started right after updating the App plugin to 3.2.9.
2. Matched it with other reports of the same crash on sites that updated to 3.2.9, so it was a regression in the release.
3. Ruled out: site-specific setup. Older App plugin versions loaded without errors on the same site.
4. Escalated to the development team, who confirmed the bug and prepared the fix.

## Solution
Update the BuddyBoss App plugin to 3.2.10 or later, which contains the fix.
Workaround until then: download the previous App plugin version from the BuddyBoss account Downloads page and upload it via Plugins > Add New > Upload Plugin, choosing to replace the current version.
Root cause: in 3.2.9 the plugin's update routine ran too early in the WordPress load, before the core function wp_get_current_user() was available, so every request crashed.

## Customer note
Thanked the team, said the site and dashboard load normally and they will update to the release with the permanent fix.
