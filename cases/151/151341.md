## Debugging steps
1. Asked whether the issue was in the Classic or Next Gen app build. It was Classic.
2. Asked the customer for the custom icon files and tested them in a dev app.
3. Reproduced the same black custom icons in a Classic dev build, so the icons were not the cause. Confirmed it was a product bug and escalated it to the development team.
4. Workaround offered: use the default icons until the fix is released. The customer could not use it because their custom icon was tied to an in-app product.

## Solution
The development team fixed the bug and released the fix. Update the BuddyBoss App plugin and BuddyBoss Platform plugin, request a new app build, upload it, then check the custom icons again.
Workaround until then: use the default icons instead of custom icons.
Root cause: A bug in the Classic app made custom toolbar icons show as solid black.

## Customer note
No reply after the fix was released. In their last reply they said the default icon workaround was not an option and asked for a fix.
