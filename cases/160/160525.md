## Debugging steps
1. Checked BuddyBoss settings on the latest Platform version: there is no Telemetry option in the dashboard.
2. Noted older versions had it under BuddyBoss > Settings > Advanced > Telemetry.
3. Asked for the Platform version and where telemetry was mentioned; the customer saw it in the WordPress Data Privacy page.
4. Checked with the development team how telemetry works in current versions.

## Solution
Expected behavior, no fix needed. Since BuddyBoss Platform 3.4.3 the Telemetry setting is shown only on sites running the free BuddyBoss Platform alone. With any paid BuddyBoss product active (BuddyBoss Theme, Platform Pro, a paid add-on or an active license key), telemetry is part of the product and cannot be disabled.
Telemetry sends only site configuration and usage statistics (server details, active BuddyBoss features, active plugins, counts of members or groups), no personal user data or user content. If there is a specific privacy or compliance requirement, raise it with the product team.
Root cause: the telemetry opt-out is hidden by design on sites with paid BuddyBoss products.
