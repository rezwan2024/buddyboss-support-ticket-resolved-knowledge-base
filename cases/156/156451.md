## Debugging steps
1. Checked the license notice in the admin dashboard, shown for paid add-ons such as Offload Media and Gamification.
2. Asked the customer to download the newest BuddyBoss add-on plugin from their account, install it, then disconnect and reconnect the license using the updated key, not the legacy key.
3. Ruled out: reinstalling the add-on and reconnecting the license. The same notice stayed.
4. Checked the installed theme and Platform Pro files over SFTP and found they were not genuine copies but nulled versions with injected license code.

## Solution
Removed the nulled license code from the theme and Platform Pro, then activated both with the customer's genuine license. Advise replacing the theme and all plugins with copies downloaded only from the BuddyBoss account, so updates and license checks work.
Root cause: the site ran nulled copies of BuddyBoss Theme and Platform Pro, whose injected license code blocked activation of the genuine license.
