## Debugging steps
1. Requested a new app build and the build failed with the resources download error.
2. The build was failing because App Center could not download the app language file from the site, under /wp-content/uploads/bbapp/.
3. Checked Cloudflare Security Events for blocked requests to /wp-content/uploads/bbapp/ and /wp-admin/admin-ajax.php with the BuddyBossBot/1.0 user agent.

## Solution
In Cloudflare, add a WAF custom rule at the top: `http.user_agent contains "BuddyBossBot"`. Set the action to Skip for Super Bot Fight Mode, Browser Integrity Check, Security Level, Rate Limiting Rules and All Managed Rules. Bot Fight Mode cannot be skipped, so turn it off during the build and turn it back on after.
If Cloudflare shows no blocks, ask the host to allow the BuddyBossBot/1.0 user agent in their firewall, ModSecurity, security plugin or .htaccess rules. Then build again.
Root cause: a security layer blocked App Center requests for the app resources because they did not come from a normal browser.
