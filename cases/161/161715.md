## Debugging steps
1. Noted the pattern: News Feed, posting, the notification bell and the app work, but Notifications, Groups, member profile and other community pages show the critical error.
2. Matched it to the known conflict between BuddyBoss Sharing and the latest Yoast SEO release.
3. Checked the PHP fatal error details on a failing page as an administrator; an error mentioning WPSEO confirms this conflict.

## Solution
Workaround until the fixed Sharing version is released: deactivate BuddyBoss Sharing, or keep it active and add this file as wp-content/mu-plugins/bb-sharing-yoast-fix.php (take a backup first, delete the file after updating Sharing):
```php
<?php
function bb_temp_skip_sharing_yoast() {
	global $wp_filter;
	foreach ( $wp_filter as $hook => $handler ) {
		foreach ( $handler->callbacks as $priority => $callbacks ) {
			foreach ( $callbacks as $cb ) {
				$fn = current( $cb );
				if ( is_array( $fn ) && 'disable_conflicting_plugins' === end( $fn ) ) {
					remove_action( $hook, $fn, $priority );
				}
			}
		}
	}
}
add_action( 'init', 'bb_temp_skip_sharing_yoast', PHP_INT_MAX );
add_action( 'wp', 'bb_temp_skip_sharing_yoast', PHP_INT_MIN );
```
While the workaround is active, Yoast may add its own social sharing tags on community pages.
Root cause: The disable_conflicting_plugins step in BuddyBoss Sharing crashes with Yoast SEO 28.7.
