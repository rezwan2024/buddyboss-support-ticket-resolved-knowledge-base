## Debugging steps
1. Checked the developer documentation and the App Codex: both cover only the Classic React Native app.
2. Confirmed custom screens, custom pages and their hooks are Classic features that need developer access on the app plan.
3. Confirmed custom code development for App Next Gen (Flutter) is not open yet and has no documentation or release date.
4. Asked the customer for the goal: code-level custom screens by user type, such as a custom landing screen for group leaders.

## Solution
Code-level custom screens are built on the Classic React Native app, which is fully supported and not being retired: follow the "Extending the BuddyBoss App" developer tutorials to replace an existing screen or add a new one to the navigation stack and branch on member data such as user type. App Next Gen custom development opens later, once Next Gen is stable.
Root cause: custom code development and its documentation exist only for the Classic app; Next Gen does not support it yet.
