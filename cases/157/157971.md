## Debugging steps
1. Checked a PDF in the activity feed in the app: it opens in a preview and the download option is available there.
2. Ruled out: filling out PDF forms inside the app. This is not supported, the app only previews and downloads PDFs.
3. Opened the PDF from a LifterLMS lesson in the app: it opens the default lesson way and no download option appears.
4. Customer workaround of linking to an app page holding the PDF worked in the app but the link did not open in a desktop web browser.
5. App team tested on the site with the lesson linking to the PDF file directly.

## Solution
In the lesson, link to the direct File URL of the PDF (Media Library > open the PDF > copy File URL) instead of an app page or embedded document. It opens in both the app and the web browser. The link can be styled as a button with CSS.
For fillable forms, host the PDF on external storage such as Google Drive or Dropbox so users open it in their device PDF app, or use a web form plugin.
Root cause: PDFs inside LifterLMS lessons open in the app's default lesson view, which has no download option, and app page links only work inside the app.

## Customer note
No reply after the direct PDF URL fix; their last reply said the app page workaround failed in the web browser.
