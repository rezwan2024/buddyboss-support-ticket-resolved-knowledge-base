2. Ruled out: WP-Cron, it was running normally on the site.
3. Tested the same scenario on a clean test site (two users message a logged-out third user, delay 5 and 15 minutes): the delayed email was sent as expected, so it is not a general Platform bug.
4. Asked for a plugin conflict test with only BuddyBoss Platform and Platform Pro active, then reactivating plugins one by one.
5. Next step suggested: set up FluentSMTP with the Gmail provider and test the delayed notification again, then full site access for deeper checks if it still fails.

## Solution
No confirmed fix, the customer stopped replying. Delayed message emails work on a clean install, so check for a plugin conflict first, then route mail through an SMTP plugin such as FluentSMTP and retest.
Root cause: not confirmed, site-specific (likely a plugin conflict or the server's email sending), not a BuddyBoss bug.
