## Debugging steps
1. Enabled WP_DEBUG and WP_DEBUG_LOG with the free Debug Log Viewer plugin, cleared the log and tapped Join again in the app.
2. Log showed the fatal in bp_parse_args() in bp-core-functions.php, called from groups_record_activity() during groups_join_group() in the REST group membership endpoint.
3. Ruled out: BuddyBoss Platform core. bp_parse_args() runs the filter bp_before_groups_record_activity_parse_args before array_merge(), and a callback on that filter returned false instead of the args array.
4. Asked for a conflict test: only BuddyBoss Platform, Platform Pro and the App plugin active, then reactivate plugins one by one until the error returns.

## Solution
Find the third-party plugin or custom code hooked to bp_before_groups_record_activity_parse_args (conflict test) and fix or remove it so the filter returns the array it received. The customer reported the issue resolved after the conflict test steps.
Root cause: third-party or custom code on the filter bp_before_groups_record_activity_parse_args returned false, so array_merge() failed when the group join activity was recorded.
