## Debugging steps
1. Tested on a dev site with the same versions: blog posts open from the Activity Feed without issue.
2. On the affected app, tapping the post image or text showed the top loading bar but the blog did not open.
3. Asked to disable optimization, security and cache plugins in case they restrict REST API loading.
4. Recorded a test in the app: tapping the post link in the activity opens the blog, tapping the post image does not.

## Solution
Not solved. Workaround given: tap the post link in the activity instead of the post image. Next steps were to disable optimization, security and cache plugins and to check if it only happens on pinned blog posts.
Root cause: Not confirmed. The post image in the Activity Feed blog activity does not reliably open the post, while the post link does.

## Customer note
Said it still happens at times, only in the Activity Feed, and suspected pinned blog posts; no reply after the link-tap workaround.
