## Debugging steps
1. Customer noticed a new version of the app after a build with the latest BuddyBoss App plugin and asked for documentation.
2. Confirmed this is the App Next Gen release, not a fault.

## Solution
Explained that App Next Gen is a complete rewrite in Flutter, and the Classic app built on React Native is still continued. Pointed the customer to the BuddyBoss doc on how to enable App Next Gen in the BuddyBoss App.
Root cause: not a bug, the latest plugin version offers the new App Next Gen.
