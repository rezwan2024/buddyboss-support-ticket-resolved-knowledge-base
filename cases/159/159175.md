## Debugging steps
1. Noted the account activation template is still part of BuddyBoss Platform; in current versions it is titled "Activate Your Account", so the old name no longer matches.
2. Searched BuddyBoss > Emails for "activate".
3. Checked the Trash view of the Emails list; a trashed template can be restored with its custom wording.
4. Template was not found in the list, so the default emails were reset.

## Solution
Go to BuddyBoss > Tools > Repair Community, tick Reset Emails and click Repair Items. This restores the default "Activate Your Account" template. It resets every email template to default, so copy any custom wording first.
Root cause: the activation email template post was missing from the site's email templates (deleted or not recreated after the update).

## Customer note
Said the template appeared again after Reset Emails and thanked the team.
