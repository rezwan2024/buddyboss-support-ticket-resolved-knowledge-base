## Debugging steps
1. Customer asked four questions before updating: minimum App plugin version for builds, Platform and Pro requirements for App plugin 3.2.4, which build meets the iOS 26 SDK rule, and written upgrade steps.
2. Ruled out: a minimum App plugin version on the build service. Older plugin versions can still request builds.
3. Ruled out: a fixed minimum Platform or Platform Pro version for App plugin 3.2.4. The supported and tested combination is the latest release of each, so no numeric matrix is published.
4. Ruled out: an older build number that meets the iOS 26 SDK rule. Apps are compiled on BuddyBoss cloud build servers, so the SDK comes from the build servers, not the site.

## Solution
Update Platform, Platform Pro, the Theme if used, and the App plugin from the WordPress dashboard update notices (check the release notes for the range first), then in BuddyBoss App > Builds click Request Build, choose iOS and Release App, and send the request (usually 15 to 30 minutes).
Upload the new build to App Store Connect and Google Play yourself or through the BuddyBoss Publishing Service. A fresh Release build meets Apple's rule that uploads since 28 April 2026 use Xcode 26 and the iOS 26 SDK; send any App Store Connect SDK rejection text to support.
Root cause: no compatibility issue; builds are made from the plugin installed at request time and the SDK is set on the BuddyBoss build servers.
