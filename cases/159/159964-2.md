## Debugging steps
1. No reCAPTCHA controls under BuddyBoss > Settings > Login & Registration, and BuddyBoss > Integrations only shows the marketplace.
2. Opening the new settings URL page=bb-settings&tab=recaptcha returns "Feature not found".
3. The bb_recaptcha option in the database still shows connection_status connected, recaptcha_version recaptcha_v3 and enabled_for flags (bb_login, bb_register, bb_lost_password, bb_activate), so reCAPTCHA keeps running.
4. Docs place the page at BuddyBoss > Settings > reCAPTCHA. Site access was asked for to check why it is missing, but the customer did not share it.

## Solution
Not fixed in the ticket. Workaround: back up the bb_recaptcha option, then edit only the enabled_for flag you need (for example bb_login from 1 to 0) directly in the option. The change takes effect right away.
Root cause: not confirmed. reCAPTCHA settings saved in an older version stay active, but the settings page does not load in the new settings interface.

Did not reply about the missing settings page after site access was asked for.
