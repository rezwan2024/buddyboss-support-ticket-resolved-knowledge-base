## Debugging steps
1. Reproduced the critical error on any single listing page, also for logged-out visitors.
2. Checked the PHP error log in a troubleshooting session that only affects the agent's login.
3. Error log pointed to HelpGent FormRepository.php get_bubble_by_page_id(), called from helpgent/enqueues/frontend-enqueue.php on wp_enqueue_scripts.
4. Ruled out: BuddyBoss. Conflict test with BuddyBoss Platform, Platform Pro and Theme active alongside Directorist showed no conflict.

## Solution
The fatal error comes from HelpGent (3.0.2, Pro 3.0.1): it loads a chat bubble for the page, gets null instead of an array and stops the page. Send the error and call stack to wpWax (makers of HelpGent and Directorist) for a fix. Deactivating HelpGent should let listing pages load in the meantime.
Root cause: HelpGent bug in get_bubble_by_page_id() passing null to array_map(), not a BuddyBoss conflict.
