## Debugging steps
1. Ruled out: the published build, since the app works on the other Android test devices.
2. Ruled out: a broken install, since uninstalling and reinstalling the app gave the same error.
3. Logged in with the access given, but the account lacked the full Administrator role, so the BuddyBoss App, Plugins and Wordfence menus were hidden and settings could not be checked.
4. Noted Wordfence is active; its blocking rules can stop app API requests from a specific country or IP.

## Solution
Asked for full Administrator access and to check Wordfence > Tools > Live Traffic for blocked requests from the user's country or IP.
Asked the user to note if the error shows on open or only after login (then test the login on another phone), switch between Wi-Fi and mobile data, turn off any VPN or ad blocker app, set Private DNS to Automatic under Settings > Connections > More connection settings, set date and time automatically, and open the site in the phone browser.
Root cause: not confirmed; most likely the app cannot reach the site API from that user's network or region, such as a security plugin block, DNS or VPN.
