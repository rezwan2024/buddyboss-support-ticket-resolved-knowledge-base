## Debugging steps
1. Confirmed the LearnDash course builder shows the correct lesson order and the LearnDash sidebar opens lessons in the right order.
2. Ruled out: LearnDash itself. learndash_next_post_link() and learndash_previous_post_link() return the correct next and previous lesson URLs on the same page.
3. Ruled out: caching. Page cache for logged-in users was off and the object cache (Redis) was flushed, the wrong links stayed.
4. Isolated the problem to the theme header links in the learndash_next_prev_link block (prev-link and next-link). The pattern (Next to the first lesson, Previous disabled, Next on the last lesson) matches the header not finding the current lesson in the course steps list and falling back to the first step.

## Solution
Open the course in the LearnDash course builder and save it to rebuild the stored course steps, then go to Settings > Permalinks and click Save Changes. Also check whether Shared Course Steps is enabled with the lesson used in more than one course, and whether the child theme has an outdated learndash template override folder.
Workaround used by the customer meanwhile: a script that reads the correct URLs from learndash_next_post_link() and learndash_previous_post_link() and rewrites the header arrows after page load, hiding Previous on the first lesson and Next on the last.
Root cause: likely the stored course steps list being out of sync with the real lesson order (or a shared lesson or old template override), so the header cannot match the current lesson. Not confirmed.
