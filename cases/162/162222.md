## Debugging steps
1. Ruled out: browser and device, the issue showed on desktop and mobile in Firefox and Safari.
2. Ruled out: WordPress image size settings, images uploaded to the WordPress Media Library displayed normally.
3. Ruled out: Offload Media as the original cause, photos were missing before it was deactivated.
4. Opened BuddyBoss photo URLs in profiles, groups and albums: all returned not found, while the original files were still on the server.
5. BuddyBoss > Settings > Media showed its own notice that symbolic links do not work on this server.

## Solution
Untick "Enable symbolic links" in BuddyBoss > Settings > Media and save. BuddyBoss then serves protected photos with its alternative method, still limited to members with permission. Photos and the video formatting both displayed correctly after this, and Offload Media could be reactivated with no extra steps.
To turn symbolic links back on later, the host must first allow symbolic links on the server.
Root cause: the server could not follow symbolic links, so BuddyBoss photo URLs returned not found.
