## Debugging steps
1. Checked the site header while logged in: the static login icon came from the active theme's own header, not from ReadyLaunch.
2. Ruled out: a missing ReadyLaunch feature. The ReadyLaunch header already shows the logged in member's avatar and a profile dropdown.
3. Noted that members upload their own profile photo from the front end, so the default avatar keeps showing until a photo is set.

## Solution
Go to BuddyBoss > Settings > Appearance > Settings > Menus and choose the site menu under the Header option, so the ReadyLaunch header with the member avatar and profile dropdown is used.
Test with an account that has a profile photo. Members set it from the header profile icon > View Profile > Edit Profile > Profile Photo.
Root cause: the header in use was the theme's own header with a static icon, not the ReadyLaunch header.
