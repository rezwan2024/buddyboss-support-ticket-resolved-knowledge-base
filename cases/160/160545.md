## Debugging steps
1. Ruled out: plugin conflict, deactivating plugins one by one made no difference.
2. Reproduced while logged out: requested a reset, opened the email link, saving the new password failed with invalid link every time.
3. Found the reset page loads the BuddyBoss Platform icon font, and with Private Network on that file request was redirected to the login page.
4. That background redirect through the login page cleared the reset session before the member pressed Save.

## Solution
In BuddyBoss > Settings > Advanced > Privacy, add this line to Public Website Content so the icon font folder is not redirected:
```
/wp-content/plugins/buddyboss-platform/bp-templates/bp-nouveau/icons/
```
Only the icon font folder becomes public, no member content or uploads. After the change the reset shows "Your password has been reset."
Root cause: Private Network redirected the icon font request on the reset page to login, which invalidated the reset session.
