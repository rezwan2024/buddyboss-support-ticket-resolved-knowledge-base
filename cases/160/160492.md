## Debugging steps
1. Checked the BuddyBoss Platform settings and code (version 3.0.3) for an option to change the composer's default destination.
2. Ruled out: a native setting. There is none for a default group or for making group selection mandatory.
3. Confirmed the composer always starts as a post to All Members on the News Feed.

## Solution
No built-in option. Built-in route: members post from inside the group, using the composer on the group's activity tab, so the post goes to that group.
For the News Feed itself, custom JavaScript can hide the All Members option and preselect a group. This is unsupported custom code: add it with a code snippets plugin such as WP Code, test on staging first, and recheck after Platform updates. The customer can submit it as a feature request.
Root cause: The Activity Feed composer has no setting for a default posting destination or a required group.
