## Debugging steps
1. Confirmed new members receive the activation email, but the activation link fails with the incorrect activation key message.
2. Flushed WordPress rewrite rules by saving the permalink settings without changes.
3. Registered a new test account and clicked the activation link; activation completed without error.

## Solution
Go to WordPress Dashboard > Settings > Permalinks and click Save Changes without changing anything, then have a new user register and activate again.
If it still fails, check page caching and exclude the activation page from cache, then test for plugin or theme conflicts.
Root cause: stale or broken rewrite rules stopped the activation page from reading the activation link correctly.
