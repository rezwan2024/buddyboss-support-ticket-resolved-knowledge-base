## Debugging steps
1. Confirmed it happens in the web browser, for multiple senders and users, since the site launched.
2. Ruled out: outdated versions. BuddyBoss Theme, Platform and Platform Pro were updated and the issue remained.
3. Had the customer send a new test message: the notification still did not open the exact DM.
4. Checked the site header: it is built with Elementor, and the message and notification icons are Elementor widgets, not the native BuddyBoss header components.

## Solution
Use the default BuddyBoss header, or the native BuddyBoss message and notification components, instead of the Elementor header widgets so each notification links to its own conversation.
Root cause: the Elementor message and notification widgets only link to the main Messages page, so clicks open the full inbox instead of the specific conversation.

## Customer note
Last reply said the notification still does not open the DM after the update; no reply after the cause was explained.
