## Debugging steps
1. Customer had a custom WordPress plugin with Mux API integration and a desktop Go Live screen, and wanted native camera and microphone broadcasting in the iOS and Android app.
2. Ruled out: custom code in the app, because the Flutter-based Next Gen app does not support custom JavaScript.
3. Confirmed the app has no native livestreaming, and no Mux support built in.

## Solution
Sent the request to the product team through the feature request process, including the customer's interest in beta testing and Mux as a video provider. No timeline given.
For native livestreaming sooner, sent the customer to the BuddyBoss Agency team, the only team that can add custom features to the Next Gen app and reuse an existing Mux backend and REST API.
Root cause: native livestreaming is not a feature of the Next Gen app, and the app cannot be extended with custom code.
