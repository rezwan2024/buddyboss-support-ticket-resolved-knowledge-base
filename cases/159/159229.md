## Debugging steps
1. Confirmed the installed versions: Platform 2.14.4 and Platform Pro 2.10.1 on a multisite network with LearnDash.
2. A security scanner plugin flagged Platform 2.14.4; the report covers Platform 3.0.5 and earlier, so 3.1.0 or later resolves it.
3. Checked the BuddyBoss account downloads: Platform 3.5.0 and Platform Pro 3.3.2 were available, plus a new license key and a legacy license key.
4. Network Admin showed no update notice for either plugin and no license screen to check the connection.

## Solution
Manual update, tested on a staging copy first: download Platform 3.5.0, Platform Pro 3.3.2 and the latest BB LearnDash add-on from the BuddyBoss account, then in Network Admin go to Plugins, Add New, Upload Plugin and choose "Replace current with uploaded" for Platform first, then Platform Pro, then the add-on. No deactivation needed.
After updating, activate with the new license key, not the legacy one (the legacy key is only for the older 2.x builds). Repeat on live once staging works.
Root cause: the old 2.x install was not receiving update notices from its license connection, so the patched version had to be installed manually.
