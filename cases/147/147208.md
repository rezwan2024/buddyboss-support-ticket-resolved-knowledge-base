## Debugging steps
1. Compared the Send Invites screen in the Legacy app and the Next Gen app: Legacy shows the Profile Type selector, Next Gen does not.
2. Ruled out: settings. "Allow users to select this profile type" was enabled on the relevant profile types in the profile type settings.
3. Reproduced on a test site with the Next Gen app and escalated to the product team as a Next Gen app bug.
4. After the first released fix the selector was still missing in new release builds, so the dev team rechecked the site's app build.

## Solution
Fixed in a later BuddyBoss App plugin and Platform update. Update the BuddyBoss App plugin and BuddyBoss Platform, send a new app build request, then install or publish the new build so users get the updated app.
Root cause: the Next Gen app did not render the profile type choice from the email invite settings that the Legacy app supported.

## Customer note
Said the profile type issue looked fixed in the latest update, then moved on to a separate group invite question.
