## Debugging steps
1. Asked whether the site uses the BuddyBoss Theme or ReadyLaunch, since each manages menus in a different place.
2. Ruled out: built-in menu settings alone, as they remove the menu on every device, not per device.
3. Asked for desktop and mobile screenshots of the header to target the right elements with CSS.

## Solution
ReadyLaunch: header menu and left side menu are managed under BuddyBoss > Settings > Appearance > Menus. BuddyBoss Theme: side nav is the BuddyPanel, switched off under BuddyBoss > Theme Options > BuddyPanel; header menu comes from Appearance > Menus.
To hide the center nav only on desktop and the side nav only on mobile, use a small custom CSS snippet with media queries targeting those elements.
Root cause: menu settings apply to all devices, so per-device hiding needs CSS.
