## Debugging steps
1. Checked the course list, single course and course details endpoints under /wp-json/buddyboss-app/learndash/v1/ all return 200 with complete data.
2. Ruled out: API CDN (disabled), API caching, WP REST Cache, WP Rocket and Redis object cache (all purged).
3. Ruled out: course image format (AVIF and PNG/JPEG courses fail the same way).
4. Ruled out: missing bridge plugin, the app was rebuilt after installing the BuddyBoss LearnDash plugin.
5. Noted PHP warning on every course request: RestCDN::rewrite_url() argument must be passed by reference, which may print output before the JSON and break parsing in the app.

## Solution
No confirmed fix. Next steps given: LearnDash 5.x is not a listed Next Gen requirement, so 4.25.6 should work; update LearnDash and all plugins, make a new build and retest. If it still fails, keep only Platform, Platform Pro, BuddyBoss App, LearnDash and the BuddyBoss LearnDash plugin active, then rebuild and retest. Also test a simple course with one lesson and no media, another user and another device, and open the course API in a browser to check the response starts directly with JSON.
Root cause: not found; suspected PHP warnings from App plugin 3.2.6 corrupting the course API response or a plugin conflict.
