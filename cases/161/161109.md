## Debugging steps
1. Opened BuddyBoss > Settings in wp-admin: the main settings page loaded, all features and toggles were listed, no errors.
2. Ruled out: a general settings page failure. Asked the customer which settings page was affected, and they named Member Blogging.
3. Opened the Member Blogging settings and saw the "Upgrade Plus" label there.
4. Checked plugin versions: BuddyBoss Platform 3.2.0 and Platform Pro 3.1.0, while the latest were 3.6.1 and 3.3.3.

## Solution
Download the latest BuddyBoss Platform and Platform Pro (plus any BuddyBoss add-ons) from the BuddyBoss account Downloads page. Upload each one under Plugins > Add New Plugin > Upload Plugin and choose "Replace current with uploaded". Then clear the server cache, CDN cache and browser cache, and check the Member Blogging settings again.
Root cause: Old, mismatched Platform and Platform Pro versions showed the newer Member Blogging feature as locked.

## Customer note
Said everything is fine and thanked the team.
