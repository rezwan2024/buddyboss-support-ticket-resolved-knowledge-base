## Debugging steps
1. Checked BuddyBoss App > Configure > iOS Settings on the site.
2. Ruled out: Apple Developer account connection, it was connected.
3. Ruled out: Bundle IDs, both Release and Test Bundle IDs were in place.
4. Found the Release signing certificate saved in the plugin is not recognized by Apple as a current certificate on the team, and no certificate is linked for the Test app.

## Solution
In the Apple Developer account, under Certificates, Identifiers and Profiles, remove expired or unused iOS Distribution certificates. In BuddyBoss App > Configure > iOS Settings > Signing Certificates, uncheck "Automatically generate signing certificates" and save, delete both saved certificates and save, then re-check the option and save again. Then click "Generate New Profiles" under Provisioning Profiles. A live App Store app is not affected; Test app installs on devices need a new build afterwards.
Root cause: the signing certificates saved in the plugin no longer matched a current certificate on the Apple team, so Apple could not create the profiles.
