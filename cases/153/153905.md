## Debugging steps
1. Build log showed the Next Gen build failing on the launch screen (splash logo) image; Classic Android and iOS builds worked.
2. Ruled out: Cloudflare cache rules and cache purge for the launch screen images did not help.
3. Ruled out: Cloudflare Polish WebP conversion of the PNG launch images; turning Polish off did not help.
4. Ruled out: disabling dark mode in the app and removing and re-uploading all branding images did not help.
5. Dev team found the App plugin sent the whole Next Gen payload (26 files, about 25 MB) in one upload with a fixed 45 second timeout; on slower hosts the upload was cut off, so later files were saved empty.

## Solution
Update the BuddyBoss App plugin to the latest version, which fixed the single-upload timeout (AppCenter side was fixed by BuddyBoss). If the site uses Cloudflare, add a WAF custom rule with action Skip (Super Bot Fight Mode, Browser Integrity Check, rate limiting and managed rules) for URI Path starts with /wp-json/ or /wp-content/uploads/ or User Agent contains BuddyBossBot, then purge cache and send a new build.
Root cause: known App plugin bug, large Next Gen build payload uploaded in one request with a fixed timeout and cut off part way.

## Customer note
Thanked the team, updated the plugin and added the rule, then reported a new build error (see case 153905-2).
