## Debugging steps
1. Ruled out: forum subscription and Forum Features settings, members were subscribed and could subscribe to discussions and forums.
2. Tested a new standalone forum: notifications sent at first, then only intermittently. Group forum notifications did not send at all.
3. Checked the SMTP plugin email log to see whether the notification emails were being generated.
4. Checked whether WordPress cron was running, since forum notification emails are sent by background scheduled tasks.
5. Found requests to /wp-cron.php were blocked by a Cloudflare firewall rule.

## Solution
Allow /wp-cron.php in the Cloudflare firewall rules (or use a real server cron) so WordPress scheduled tasks can run. After the fix, the queued notification emails were sent at once.
Root cause: a CDN firewall rule blocked wp-cron.php, so the background email queue for forum notifications never ran.
