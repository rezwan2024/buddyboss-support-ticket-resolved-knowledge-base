## Debugging steps
1. Requested a new app build. It failed in App Center with the resource download error.
2. Development found that App Center could not download the app language file from the site. A server security layer blocked the request because it came from the App Center, not a browser.
3. Checked Cloudflare Security Events for blocked requests to /wp-content/uploads/bbapp/ and /wp-admin/admin-ajax.php from the BuddyBossBot/1.0 user agent.

## Solution
In Cloudflare, add a WAF Custom Rule at the top of the list: `http.user_agent contains "BuddyBossBot"`. Set the action to Skip and select Super Bot Fight Mode, Browser Integrity Check, Security Level, Rate Limiting Rules and All Managed Rules.
A custom rule cannot bypass Bot Fight Mode, so turn it off while the build runs and turn it back on afterwards. If Cloudflare shows no blocks, ask the host to allow the BuddyBossBot/1.0 user agent in its firewall, ModSecurity, security plugin or .htaccess rules.
Root cause: Server-side bot protection blocked the App Center request for the language file that the build needs.
