## Debugging steps
1. Customer saw the Tutor Dashboard stop working correctly right after updating Tutor LMS to 4.0.
2. Switched the theme to Twenty Twenty-Five: the Tutor Dashboard worked, so the issue is with the BuddyBoss Theme.
3. Confirmed as a known bug: the Tutor LMS 4.0 dashboard layout breaks with the BuddyBoss Theme.

## Solution
A compatibility fix was released. Update the BuddyBoss Theme, BuddyBoss Platform and all other plugins to the latest versions, then clear all site and browser caches and recheck the Tutor Dashboard.
Root cause: Tutor LMS 4.0 changed its dashboard, and the BuddyBoss Theme styling for it was not compatible with the new version.
