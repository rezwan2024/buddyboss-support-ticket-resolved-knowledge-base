## Debugging steps
1. Opened a restricted course while logged out and saw the English message at the top of the login page.
2. Ruled out: missing translation string. The text is not in a .po file, so Loco Translate cannot change it.
3. Found the text is saved in the Default Unauthorized Message field under Membership > Settings > Pages > Unauthorized Access, still holding the English default.
4. Tested logged out with the cache bypassed after the change. A normal load still showed the old English text from the page cache.

## Solution
Type the translated text into Membership > Settings > Pages > Unauthorized Access > Default Unauthorized Message and save. Links and formatting can be added there too. Then clear the site page cache.
Root cause: the message is a saved settings value, not a translatable string, so translation plugins do not affect it.
