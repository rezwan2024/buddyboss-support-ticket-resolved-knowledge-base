## Debugging steps
1. Got a screen recording and screenshots of the Messages list scrolling back on the iPad and iPhone.
2. Ruled out: site and message data. All conversations load correctly on the website.
3. Found the live App Store version was months older than the site's BuddyBoss App and Platform plugins.
4. Found the latest iOS build attempt had failed on an Apple signing setting, so no newer app version had been released.

## Solution
In the Apple Developer account, under Certificates, Identifiers and Profiles, Identifiers, enable Associated Domains on the test App ID and the main App ID and save. In BuddyBoss App, Configure, iOS Settings: untick generate on the Signing Certificate, save, delete the certificate, save. Do the same for automatic Provisioning Profiles. Then tick both again, save, and create a new iOS build.
Submit the completed build in App Store Connect, release it, and have members update the app. Then the Messages list keeps loading older conversations as they scroll.
Root cause: the installed app build was older than the site plugins because the iOS build had failed, as Associated Domains was missing from the App ID signing setup.
