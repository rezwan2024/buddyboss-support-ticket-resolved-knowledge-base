## Debugging steps
1. Checked the auto-generated Courses directory page: it is a community component page, so it renders inside the community layout and shows the community left navigation by design.
2. Ruled out: a built-in shortcode or Elementor widget for a standalone public course catalog, BuddyBoss Courses does not ship one.
3. Confirmed the customer has Elementor Pro, so the Loop Grid and Posts widgets are available.

## Solution
Create a normal WordPress page outside the community, edit it with Elementor Pro, add a Loop Grid or Posts widget with the query source set to the Courses post type, and show only featured image, title and excerpt. The page has no community navigation and is visible to logged out visitors. Set each course's Sales Page field to a public landing page so visitors are not sent into the protected course view. On Elementor free, use a small custom query in a child theme instead.
Root cause: the Courses directory is a community component page and always inherits the community layout and navigation.
