## Solution
Workaround: hide or move the section with a small custom CSS rule targeting the share block on single posts, added in the Customizer Additional CSS or the theme custom CSS area. The exact CSS was not given in this ticket; the agent asked for a separate ticket with a blog post link.
Root cause: the theme adds the share section to single posts with no toggle to turn it off.
