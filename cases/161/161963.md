## Debugging steps
1. Reproduced the critical error as an administrator on Account Settings and the other BuddyPanel and profile menu pages.
2. Ruled out: switching PHP back from 8.5 to 8.2, the error stayed.
3. Ruled out: the recent move from LearnDash to BuddyBoss Courses and from WooCommerce Memberships to BuddyBoss Memberships.
4. Used Query Monitor to read the fatal error behind the critical error message. It pointed to BuddyBoss Sharing calling WPSEO_Frontend::get_instance() in Plugin_Compatibility.php around line 134.

## Solution
Workaround until the fixed Sharing release: deactivate BuddyBoss Sharing, or keep it active and edit Plugin_Compatibility.php around line 134 so it checks that the class exists first (a plugin update overwrites this edit):
```php
$frontend = is_callable( array( '\WPSEO_Frontend', 'get_instance' ) ) ? \WPSEO_Frontend::get_instance() : null;
```
Root cause: the latest Yoast SEO removed the old WPSEO_Frontend class, and BuddyBoss Sharing calls it without checking that it exists. Known bug, fix in progress.

## Customer note
Deactivated BuddyBoss Sharing, said the site works again for logged-in users and thanked the team.
