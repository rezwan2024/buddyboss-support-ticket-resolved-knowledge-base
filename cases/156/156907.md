## Debugging steps
1. Checked the site setup with the temporary admin access: BuddyBoss App plugin, Platform, theme and BB LearnDash plugin.
2. Ruled out: a separate migration process. The build servers always compile against the latest public BuddyBoss App version.
3. Ruled out: LearnDash changes. Courses and the LearnDash licence are not affected by an app update.

## Solution
Update BuddyBoss App, Platform, the theme and BB LearnDash, confirm the app is still connected under BuddyBoss App > Connect, then request a new Release build under BuddyBoss App > Build (a Test build first is advised to check course screens). Submit it to each store as an update of the same App ID. The checklists do not need to be repeated.
To skip manual uploads, set up the Upload Configuration under BuddyBoss App > Configure > iOS Settings and send Release builds from BuddyBoss App > Upload to App Store Connect or Google Play Console. Store review always stays manual. The paid BuddyBoss Publishing Service can handle the submission instead.
Root cause: no migration is needed. A new Release build is made on the current app version automatically, and content, users and store listings stay the same.
