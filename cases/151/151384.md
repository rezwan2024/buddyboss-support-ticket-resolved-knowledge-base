## Debugging steps
1. Confirmed the dashboard layout broke only after updating Tutor LMS from 3.x to 4.0 with BuddyBoss Theme active.
2. Matched it to a known theme compatibility bug: Tutor LMS 4.0 markup changes break the BuddyBoss Theme styling of Tutor LMS pages.
3. Checked the site ran the latest BuddyBoss Theme and Platform.

## Solution
Update BuddyBoss Theme to 2.22.4 or later, which adds Tutor LMS 4.0 dashboard compatibility.
Workaround until updating: roll Tutor LMS back to the latest 3.x version.
Root cause: Tutor LMS 4.0 changed its dashboard markup, and the BuddyBoss Theme Tutor LMS styles did not support it yet.
