## Debugging steps
1. Customer report: a shortcode typed in a group name renders its output in the ReadyLaunch group header, while the browser title, the visibility notice and the My Groups list show it as plain text.
2. Ruled out by customer: escaping through bp_get_group_name, bp_get_current_group_name, groups_get_group, groups_get_current_group and groups_group_name_before_save filters did not change the header, though the same method worked for the group description and forum topic titles.
3. Asked for a screen recording and the exact Platform, Platform Pro and Theme versions; customer had already added custom snippets and could only give Platform 3.4.4.
4. Tested on a clean install of Platform 3.4.4 with ReadyLaunch: a group name with a shortcode wrapped in marker words printed as text in the header. Not reproduced.

## Solution
Not reproduced on a clean install, so the cause is likely site specific. Next step: reproduce on a staging copy with the custom snippets turned off, and review any snippets that hook the group name, since they can change how the header renders it.
Root cause: not found; the clean ReadyLaunch header shows the group name as text.
