## Debugging steps
1. Reproduced: video files of 72 MB and 82 MB fail to upload to an activity post.
2. Ruled out: BuddyBoss media setting, Settings > Media > Video max size was already 1024 MB.
3. Checked the server PHP upload limit (Site Health > Info > Server) and found it lower than both video files.

## Solution
Ask the host to raise the PHP limits. The BuddyBoss video size setting is only an upper bound and cannot go above the server limit:
```
upload_max_filesize = 500M
post_max_size = 2000M
max_execution_time = 3000
max_input_time = 3000
memory_limit = 2000M
```
These values are enough for videos around 100 MB. Also advise MP4 with H.264, because many browsers do not play the H.265 HEVC files that newer iPhones record by default.
Root cause: the server PHP upload limit was lower than the video file size, so the server blocked the upload whatever the BuddyBoss setting said.
