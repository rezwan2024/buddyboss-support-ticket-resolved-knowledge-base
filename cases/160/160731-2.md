## Debugging steps
1. Ruled out: outdated plugins. BuddyBoss Platform, Platform Pro and Theme were all on the latest versions.
2. Ruled out: license state. The license page showed BuddyBoss Web enabled with a free site activation.
3. Confirmed from screenshots the notice comes from the BuddyBoss Membership license check and shows on every admin page.
4. Logged in as admin after the cache steps: the notice no longer showed on the admin pages.

## Solution
Refresh the cached license status: on the BuddyBoss license page click Deactivate License, then activate again with the key from the Subscriptions tab of the BuddyBoss.com account. Clear the server cache and any object cache (Redis or Memcached), allow up to two days, then clear the browser cache and log in again.
Root cause: an old license status (from before the license was fixed) stayed cached on the server or in the browser.
