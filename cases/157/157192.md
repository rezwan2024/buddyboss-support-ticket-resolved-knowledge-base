## Debugging steps
1. Checked the screen recording: only the course status labels on the Courses screen showed default colors instead of the custom ones.
2. Asked which branding fields were changed, whether other screens (header, tab bar, buttons, links) showed the custom colors, and when the tested build was created.
3. Found that the saved branding color values had been cleared when the site was upgraded to the new BuddyBoss version for App 3.0 Next Gen.
4. After the colors were set again, compared the course label colors (Start Course and the others) on the website and in the app build: they matched.

## Solution
Set the custom colors again in BuddyBoss App > Branding > Colors, including the Courses color settings, and save. The course status labels then show the custom colors.
Root cause: the earlier branding color values were not kept after the upgrade to the App 3.0 Next Gen version, so the app fell back to the default colors.

## Customer note
Said the colors were all good after setting them again and thanked the team.
