## Debugging steps
1. The WordPress error log showed nothing, so the build upload log was checked in App Center.
2. The log showed Apple's authorization server rejecting the App Store Connect credentials, not a build or site problem.
3. Found the App-Specific Password field held the same value as the App Specific Shared Secret field in iOS Settings.

## Solution
Generate a new app-specific password for the Apple ID under Sign-In and Security > App-Specific Passwords, then paste it only into the App-Specific Password field in BuddyBoss App > Configure > iOS Settings > Upload Configuration. Keep the Shared Secret as its own separate value. Save and retry the upload.
Also check that the Apple ID still has the Admin or App Manager role for the app and that no Apple Developer Program or Paid Apps agreements are waiting to be accepted.
Root cause: an expired, revoked or wrong app-specific password (Apple revokes them when the Apple ID password changes), here the Shared Secret pasted into the password field.
