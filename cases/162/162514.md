## Debugging steps
1. Confirmed the new account exists in WordPress admin as a subscriber and its profile page loads.
2. Ruled out: Repair Member Profiles tool and clearing the cache did not change the list.
3. Searched the Members directory by username, email and last name; the new member was missing and a similar result was a different existing member.
4. Checked the account and found it has no last active record, meaning the user has never logged in since registering.

## Solution
Expected behavior, no fix needed. Ask the member to log in once; after the first login the last active record is set and the member appears in the Members directory and its search.
Root cause: the Members directory and search list members based on their last active record, which only exists after the first login.
