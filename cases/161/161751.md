## Debugging steps
1. Checked the screenshot of BuddyBoss > Settings > LearnDash: every option showed "Requires Plugin to Activate".
2. Confirmed LearnDash LMS was not in the admin sidebar, so the LearnDash plugin was not installed and active.
3. Found the customer's quizzes were built in BB Courses, not LearnDash.
4. Ruled out: a BuddyBoss bug. The message is expected when LearnDash itself is not active.

## Solution
Explained that BuddyBoss plans include the LearnDash integration, not the LearnDash plugin. LearnDash is a separate plugin with its own license bought from LearnDash. The BuddyBoss > Settings > LearnDash page only works on sites that have LearnDash installed and active.
BB Courses is BuddyBoss's own course system with courses, lessons and quizzes, so a site needs only one of them. The customer kept using BB Courses.
Root cause: The customer read "LearnDash integration" on the pricing page as the LearnDash plugin being included in the plan.

## Customer note
Said everything is great and they are fine with BB Courses, but asked again why the pricing page lists LearnDash in the Launch plan.
