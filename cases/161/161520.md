## Debugging steps
1. Checked the exact source string: the post box text is "Share what's on your mind, %s..." in the buddyboss text domain, where %s is the member's name.
2. Added a gettext filter for that string. Ruled out: child theme functions.php, because the child theme was not active, so the code had no effect there.
3. Customer then added the same code with Code Snippets and got "Cannot redeclare function", because the function was already loaded from the parent theme functions.php.

## Solution
Add this with the Code Snippets plugin, or in an active child theme's functions.php, and change the text. Keep ", %s" to show the member's name, or remove it.
```php
add_filter( 'gettext', 'kb_custom_whats_new_placeholder', 20, 3 );
function kb_custom_whats_new_placeholder( $translated, $text, $domain ) {
	if ( 'buddyboss' === $domain && 'Share what\'s on your mind, %s...' === $text ) {
		$translated = 'Your custom text here, %s...';
	}
	return $translated;
}
```
For "Cannot redeclare function", remove the same code block from the BuddyBoss Theme functions.php (Appearance > Theme File Editor), then activate the snippet. Code in the parent theme is lost when the theme updates.
Root cause: No setting for this text, so it needs a gettext filter. The redeclare error came from loading the same function twice.
