## Debugging steps
1. Ruled out: Loco Translate files. They only change web strings from Platform and Theme. The app uses BuddyBoss App > Translations.
2. Ruled out: the language selector. English is the source language, so blank Translation fields on English are expected. The English Translation field can be used to change English wording.
3. Searched by Source Text ID for ld_mark_as_incomplete. It was not found, and the lesson screen in the app showed the raw key.
4. Ruled out: Download CSV backup and Re-import Strings did not add the missing string.
5. Ruled out: the quiz complete and incomplete strings. They are for LearnDash quizzes, not lesson buttons.
6. Reproduced on a clean test site. ld_mark_as_complete was in the list but ld_mark_as_incomplete was not, so this was a product bug.

## Solution
The development team added ld_mark_as_incomplete to the app string set and set up a weekly string sync. Go to BuddyBoss App > Translations, search for "mark as", enter the wording for Mark As Complete and Mark As Incomplete (English selector is fine), save, then force close and reopen the app.
For a test app the new wording only appears after a new app build is created and installed.
Root cause: the Next Gen app string set did not include the LearnDash lesson Mark as Incomplete key, so it could not be translated and the app showed the raw key.
