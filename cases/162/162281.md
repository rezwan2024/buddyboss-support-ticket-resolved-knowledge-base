## Debugging steps
1. Confirmed the customer wants to move existing LearnDash courses and active students into BuddyBoss Courses.
2. Checked BB Courses > Settings > Migrator, which detects LearnDash course data on the site.
3. Ran the migrator to confirm it moves courses, lessons and quizzes, and offers a "Migrate user progress and quiz attempts" option.

## Solution
Use BB Courses > Settings > Migrator and enable "Migrate user progress and quiz attempts" so students keep their place.
Take a full backup and run it on a staging copy first, then log in as a student to check courses and progress before running it on the live site.
Root cause: How-to question; BuddyBoss Courses has a built-in LearnDash migrator.
