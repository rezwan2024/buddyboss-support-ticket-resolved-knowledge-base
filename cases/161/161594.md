## Debugging steps
1. Checked the customer screenshot: the screen is the app's own update prompt, not a crash.
2. Compared Minimum iOS Build Version and Minimum Android Build Version in BuddyBoss App > Configure > General with the build live in the stores.
3. Checked the live build: Ready for Distribution in App Store Connect for iOS, current Production release in Google Play Console for Android, matched against BuddyBoss App > Builds.

## Solution
If a minimum build value is higher than the live build for that platform, set it to the live build number in BuddyBoss App > Configure > General, click Save Settings, then fully close and reopen the app.
Root cause: the minimum build version on the site was set higher than the build available in the store, so the app asked members to update to a version they could not download.
