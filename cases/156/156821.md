## Debugging steps
1. Reproduced: downloaded a LearnDash course in the app, switched to Flight Mode; MP4 videos played, MP3 audio from the Media Library did not.
2. Ruled out: file hosting, both file types were in the WordPress Media Library and embedded with Gutenberg blocks.
3. First answer said offline downloads cover video only; customer pushed back since the course is advertised as available offline.
4. Escalated to the development team, which confirmed it as a bug.

## Solution
Fixed in a later release. Update the BuddyBoss App plugin and BuddyBoss Platform plugin, then request a new app build and upload it so live users get the updated app.
Root cause: an app bug left audio files out of the offline course download package.

## Customer note
No reply after the fix was released; the last customer reply thanked the team for confirming the bug and reported a second offline issue.
