## Debugging steps
1. Customer needed clean copies of the installed old versions to diff against the live files and find direct edits to core files.
2. Ruled out: downloading the installed plugins from the dashboard (for example with a plugin download plugin), since that only copies the possibly modified files.
3. Checked internally: old Theme and Platform Pro packages are not kept as distributable copies.

## Solution
Platform: download the exact version source archive from the release tags of the public BuddyBoss Platform GitHub repository and compare it with the installed files.
Theme and Platform Pro (workaround): download the current versions from the BuddyBoss account and compare; differences include version changes but give a shortlist of modified files. Compare the child theme against the parent to see proper overrides.
Move any found core edits into a child theme or a small custom plugin before upgrading, because the upgrade overwrites core files.
Root cause: Only the open source Platform has all old releases public; old Theme and Platform Pro packages are not available.
