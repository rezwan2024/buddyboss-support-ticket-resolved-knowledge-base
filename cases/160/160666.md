## Debugging steps
1. Checked the error screenshot from the iOS Settings connect screen: the message comes from Apple, not from the BuddyBoss App plugin.
2. Ruled out: the API key. A newly created App Store Connect API key gave the same error, because Apple blocks the account, not the key.
3. Identified an Apple Developer agreement that was not accepted or had expired, which blocks App Store Connect API access.

## Solution
The Account Holder of the Apple Developer account accepts any updated agreement at developer.apple.com/account, then in App Store Connect > Business > Agreements makes sure every agreement shows Active and accepts any pending or expired one.
Then in WordPress admin go to BuddyBoss App > Configure > iOS Settings and click Connect Account again. The existing API key can be kept.
Root cause: an unaccepted or expired Apple Developer agreement blocks the App Store Connect API used by the plugin.
