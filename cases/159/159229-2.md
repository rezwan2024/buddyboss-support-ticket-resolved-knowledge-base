## Debugging steps
1. New user created on a subsite; the activation email sent fine, but opening the activation link showed the critical error.
2. Opened wp-activate.php with no activation key: same critical error, so it fails when the page loads, not for one user or key.
3. Ruled out: network registration setting. Changing it from "Registration is disabled" to "User accounts may be registered" made no difference.
4. Asked for the cause of the error: the WordPress "technical issue" email to the site admin, or WP_DEBUG and WP_DEBUG_LOG enabled with WP_DEBUG_DISPLAY off on staging, then the new lines from the debug log.

## Solution
Update Platform to 3.5.0 and Platform Pro to 3.3.2 (plus the latest BB LearnDash add-on) on a staging copy, then load wp-activate.php again. If the error is gone, repeat on live; if not, the debug log entry is needed to find the failing file.
Root cause: not confirmed; suspected to be the outdated Platform 2.14.x on the multisite activation page.
