## Debugging steps
1. Opened the course overview page directly and with a filter applied: the wrong card appears only without a filter.
2. Checked the page in the editor: its only content is the Tutor LMS courses shortcode with course_filter="on" and show_pagination="on".
3. Found the card is the page itself, shown as a course card with the page title, and its button links back to the same page.
4. Ruled out: caching, tested logged out and as admin with cache bypassed, same result.
5. Ruled out: deleted demo courses, they are not loaded at all.

## Solution
Workaround: link to the course overview page with a filter parameter added to the URL, or use the Tutor LMS course archive page, which shows the correct list without any parameter.
Also check course visibility: courses set to Private do not show on a public course list.
Root cause: in Tutor LMS 4.1.1 the courses shortcode with course_filter="on" does not run its own course query when no filter is set, so it renders the current page as a course card.
