## Debugging steps
1. Compared the Send Invites screen in the Legacy app and the Next Gen app: Legacy hides the Invite Using Link option, Next Gen shows it.
2. Checked the email invite settings in the WordPress dashboard; no separate toggle for invite by link was found there.
3. Customer explained the site uses invite-only registration, so the shared link only leads to a registration page where people cannot sign up.
4. Reproduced the link redirecting to the registration page and escalated to the product team together with the profile type issue.

## Solution
Reported as fixed and released together with the Next Gen invite profile type fix. Update the BuddyBoss App plugin and BuddyBoss Platform, send a new app build request and publish the new build, then recheck the invite options.
Root cause: the Next Gen app showed the invite link option without respecting the site's invite-only registration setup, unlike the Legacy app.
