## Debugging steps
1. Checked the installer page screenshot: the Device Information line showed a desktop OS (Linux or Windows) instead of Android.
2. Ruled out: the plugin update and the build itself. The installer did not detect an Android device, so it blocked the download.
3. Pointed to the recommended install flow: BuddyBoss App > Builds > Build History > Install Test App, then scan the QR code with the Android phone.

## Solution
In the phone browser that opens the installer page, turn off the "Desktop site" option, then reload the page and download and install the test build.
If "Unable to Install" comes back, check the Device Information line at the bottom of the installer page. It should show Android.
Root cause: the mobile browser had Desktop site turned on by default, so it reported itself as a desktop browser and the installer refused the download.

## Customer note
Said turning off Desktop site fixed it, the package downloaded normally, and thanked the team.
