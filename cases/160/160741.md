## Debugging steps
1. Checked the first release builds: both were created at version 0.0.1 (build 2), lower than the live Android and iOS apps.
2. Ruled out: changing the version of existing builds. The version is built into the app, so new release builds are needed.
3. Found the version fields in the Request Build flow, Step 2: Review Information.

## Solution
In WordPress admin go to BuddyBoss App > Build > Request Build, choose the platform and Release App, continue to Step 2: Review Information, click the pencil icon next to Build Version and Build Version Code, set them higher than the live store app (for example 3.0.0 and a code above the live one), then click Send Build Request. Repeat for each platform.
Root cause: release builds default to 0.0.1 unless the version is set by hand when requesting the build, and finished builds cannot be changed.
