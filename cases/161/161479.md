## Debugging steps
1. Checked BuddyBoss App Access Controls: Restrict Access limited to one profile type group. "Any" or "all" makes no difference with a single group.
2. Ruled out: Access Controls, since members still could not log in with Restrict Access switched off.
3. Created a test subscriber account: app login failed for it, but an administrator account logged in fine.
4. Ruled out: REST API reachability, since the API responded normally.
5. Deactivated the WP 2FA plugin: the test subscriber could log in to the app right away.

## Solution
Deactivate WP 2FA, or keep it and limit its policy to administrator and editor roles so members can still log in to the app. BuddyBoss has no official WP 2FA integration, so ask the WP 2FA developer (Melapress) for a compatible update or setting.
Root cause: WP 2FA blocks the login requests the BuddyBoss App sends for member roles.

## Customer note
Said the app login works now with WP 2FA off, and closed with "All clear. Will do so."
