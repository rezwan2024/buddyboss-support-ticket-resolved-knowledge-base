## Debugging steps
1. Ruled out: stale app session. Fully closing the app, reopening it and logging out and back in did not change the behavior.
2. Ruled out: old release build. The live App Store app and a TestFlight test build behaved the same, so it is site configuration, not the build.
3. Checked the in-app products: a free Basic product and a paid Pro product both had "Show on Course(s)" enabled with Show on set to All Courses.
4. Checked how that setting works: it does not grant or block access. It only shows a product on courses whose LearnDash access mode is Buy Now, Recurring or Closed, and only to users who are not enrolled. A prompt on every course means the courses are not really Free or Open.
5. Checked access: an in-app purchase only enrolls the user in the PMPro level. Course access comes from the LearnDash access mode plus the PMPro level-to-course mapping.

## Solution
In LearnDash, set the courses that should be free to Open (or Free if users should still be enrolled). In Paid Memberships Pro, make sure the free level grants access to the courses meant for everyone. In each in-app product, change Show on from All Courses to only the paid courses that product unlocks. No new app build is needed.
Root cause: the courses were in a paid or Closed LearnDash access mode with PMPro access tied to the Pro level, so the app offered the Pro upgrade on every course.
