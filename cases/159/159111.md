## Debugging steps
1. Customer asked how to change the First Name character limit on registration and if add_filter() is needed.
2. Confirmed the default limit for the First Name field is 32 characters.
3. Found the filter bb_xprofile_field_character_max_length controls this limit.

## Solution
Add this with a code snippet plugin or the child theme functions.php, and set the number to the limit you want (higher or lower):
```php
add_filter( 'bb_xprofile_field_character_max_length', function () {
	return 50;
} );
```
The new limit applies on the registration form, profile edits and user edit in wp-admin. Test by registering with a longer first name.
Root cause: BuddyBoss sets a default 32 character maximum on the First Name profile field, changeable only by filter.
