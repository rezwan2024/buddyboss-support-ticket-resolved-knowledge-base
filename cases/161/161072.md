## Debugging steps
1. Ruled out: missing groups, inactive Groups component, wrong Groups directory page mapping, admin access and missing group template files.
2. Traced a logged-in request to a single group page and found the fatal error in the PHP log.
3. The stack trace pointed to Plugin_Compatibility->disable_yoast_seo() called from disable_conflicting_plugins() in BuddyBoss Sharing.
4. Reproduced the same fatal error with Sharing and a current Yoast SEO active on a test site, confirmed as a Sharing bug.

## Solution
Update BuddyBoss Sharing to 2.1.2 or later. Workaround before the update: guard the call on line 134 of Plugin_Compatibility.php, which a Sharing update will overwrite:
```php
$frontend = is_callable( array( '\WPSEO_Frontend', 'get_instance' ) ) ? \WPSEO_Frontend::get_instance() : null;
```
Root cause: Sharing called WPSEO_Frontend::get_instance() to remove the Yoast OpenGraph output without checking the class exists, and newer Yoast SEO versions no longer have that class.
