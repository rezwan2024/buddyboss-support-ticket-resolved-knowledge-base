## Debugging steps
1. Noted only the app fails while the website works, and all groups, forums and blogs fail at once, which points to the REST API layer, not the content.
2. Checked Settings > Permalinks is Post name, not Plain, and re-saved it to rebuild the rewrite rules after the renaming.
3. Opened the site's /wp-json/ index while logged in as admin to confirm the buddyboss/v1 namespace is listed.
4. Checked BuddyBoss > Dashboard for "Restrict REST API access to only logged-in members" and turned it off temporarily to test.
5. Checked security plugin, firewall and CDN for blocked /wp-json/* requests, then purged server, plugin and CDN caches.
6. Confirmed WordPress Address and Site Address match the domain the app was built for, and BuddyBoss Platform and BuddyBoss App are active and updated.

## Solution
Re-save permalinks (Post name), make sure /wp-json/* is not blocked or restricted, purge all caches, confirm site URLs match the app's domain and plugins are updated, then fully close and reopen the app. The customer reported it working better after these steps without saying which one fixed it.
Root cause: app REST API requests did not reach the right endpoints after the site renaming, most likely stale rewrite rules or blocked or cached /wp-json/ requests.

## Customer note
Thanked the team and said things are better now, will report if anything else comes up.
