## Debugging steps
1. Checked BuddyBoss registration settings for an option to turn off the activation email.
2. Ruled out: a built-in setting, there is none to skip account activation by email.

## Solution
Add this PHP snippet with a code snippet plugin (WPCode or Code Snippets), set to run everywhere. It skips the activation email, activates the account, logs the member in and redirects to the homepage. Deactivate the snippet to undo. Add a CAPTCHA to the registration form to limit spam signups.
```php
add_filter( 'bp_core_signup_send_activation_key', '__return_false' );
add_action( 'bp_core_signup_user', function ( $user_id ) {
	$key = get_user_meta( $user_id, 'activation_key', true );
	if ( empty( $key ) ) {
		return;
	}
	$activated = bp_core_activate_signup( $key );
	if ( is_wp_error( $activated ) ) {
		return;
	}
	wp_set_current_user( $user_id );
	wp_set_auth_cookie( $user_id, true );
	wp_safe_redirect( home_url( '/' ) );
	exit;
}, 999 );
```
Root cause: BuddyBoss always requires email activation for new signups and has no setting to turn it off.
