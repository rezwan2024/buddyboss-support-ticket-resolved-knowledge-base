## Debugging steps
1. Ruled out: settings. "Remove media from server after uploading to Cloudflare" was on, offloading enabled for BuddyBoss Media, WordPress Media and avatars and covers, Cloudflare connected.
2. Checked Cloudflare Hosted Images variants: WordPress and BuddyBoss media sizes were registered.
3. Compared leftover files in wp-content/uploads/bb_medias with the offload records on the site and with what is stored in Cloudflare Images.
4. Reproduced with a test member uploading test photos and checked which files the cleanup removed: phone photos left a set of size files behind, regular photos were cleaned up correctly.

## Solution
Plugin bug, reported to the development team for a fix. Images still load from Cloudflare, so only server space is affected. Advise the customer not to delete the leftover files manually and to wait for the fix and a safe cleanup method.
Root cause: for photos with rotation data, WordPress saves a rotated copy; the plugin creates size files from the rotated copy but WordPress records a different set, and "Remove media from server" deletes only the recorded set. The "Offload All Media" process can leave sizes behind in a similar way.
