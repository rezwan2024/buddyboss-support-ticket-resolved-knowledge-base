## Debugging steps
1. Logged out and checked every login and register route: the custom login page, the WooCommerce my-account page and the BuddyBoss register page.
2. Found the membership plugin registration form shortcode pasted into the login page, so login and register pages showed the same registration fields.
3. Found BuddyBoss still offering its own registration form next to the membership plugin form.
4. Found the membership plugin redirecting new users to the BuddyBoss Activate account page, which asks for a key these users never get and was restricted to members only.

## Solution
Removed the registration shortcode from the login page so it shows only the membership plugin login form. In the BuddyBoss registration settings, set BuddyBoss to use the membership plugin's custom registration page, so there is one registration route with all plans. Changed the membership plugin redirect after registration from the Activate account page to the login page.
Optional: added a profile tab that shows the plugin's subscriptions and payments inside the BuddyBoss profile.
Root cause: three registration systems were active at once, and accounts created by the membership plugin were sent to the BuddyBoss activation page that only works for BuddyBoss registrations.
