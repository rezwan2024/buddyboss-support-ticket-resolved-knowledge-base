## Debugging steps
1. One admin saw a blank page after login while other admins saw the site normally. Ruled out: browser cache and cookies, clearing them did not help.
2. Read the stack trace: the fatal fires in bb_render_activity_following_post_notification during the heartbeat on-screen notifications check, so it only hits users who have that notification.
3. Found the "new post from someone you follow" notification tried to load a poll attached to the post, and the poll object was null.
4. Checked BuddyBoss, License Keys: the license key was not connected on the site, so Platform Pro features such as polls could not load, which set off the error.

## Solution
Update BuddyBoss Platform to 3.5.0 or later, which adds a check at that line so the notification no longer crashes. Connect the license key in BuddyBoss, License Keys so Platform Pro features such as polls load.
Root cause: Platform 3.4.3 did not check for a missing poll when rendering a following post notification, and polls could not load without a connected license.
