## Debugging steps
1. Checked the customer's screenshot to find which elements they meant: the forum name labels shown next to each topic in the discussions list.
2. Ruled out: a separate color setting for these labels. BuddyBoss has no option just for them.
3. Labels most likely follow the Secondary Button colors in BuddyBoss > Theme Options > Colors.

## Solution
Change the Secondary Button colors in BuddyBoss > Theme Options > Colors, save, and refresh the forums page to check that the labels change with them. These colors are also used by other buttons on the site.
To change only the discussion labels, add custom CSS under BuddyBoss > Theme Options > Custom Codes with the background and text color you want.
Root cause: the forum name labels use the theme's Secondary Button colors, not a color setting of their own.
