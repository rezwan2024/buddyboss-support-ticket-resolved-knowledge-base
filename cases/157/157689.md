## Debugging steps
1. Read the stack trace: the error came from an admin-ajax background request fired while working in wp-admin.
2. Matched the timing to the plugin update: WordPress removes the old plugin folder and unpacks the new one, so a request in that window can hit a file that is not in place yet.
3. Ruled out: a broken install. Front end and wp-admin loaded normally, BuddyBoss App showed version 3.2.3 and active, and the BuddyBossMembership integration file existed in the plugin folder.
4. Ruled out: LearnDash breakage. A LearnDash course page and the BuddyBoss App settings screen opened without errors.

## Solution
No fix needed: a one-time fatal error email right after a plugin update is a side effect of a request landing mid-update. Confirm the site loads, the plugin version is correct, the class file exists, and watch for repeat emails over the next day. Repeated emails would point to a real problem.
Root cause: an admin-ajax request ran while the plugin files were being replaced during the update.
