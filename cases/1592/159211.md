## Debugging steps
1. Confirmed the header navigation and profile icon were missing only on mobile and only for logged-in members, across several sections at once, pointing to the shared header/layout rather than each feature.
2. Logged in as a regular member on a mobile browser to reproduce.
3. Checked BuddyBoss > Settings > Appearance > General > Template Pages and found the Course Template was not using ReadyLaunch.

## Solution
Enable the ReadyLaunch course template in BuddyBoss > Settings > Appearance > General > Template Pages > Course Template, then clear the page cache (e.g. WP Rocket). The mobile header with hamburger menu and profile icon then shows correctly.
Root cause: the Course Template was not set to ReadyLaunch, so course pages loaded without the ReadyLaunch mobile header.
