## Debugging steps
1. Confirmed the Delete option is missing for regular members on both web and app.
2. Checked with the development team: removing Delete for regular members is intended behaviour, not a bug.
3. Ruled out: a setting to turn it on. There is no option that lets members delete their own discussions.

## Solution
Explained that only site admins can delete discussions; members can edit their own. An admin can delete a discussion for a member from the discussion's options menu. Feedback passed to the development team, and the customer was pointed to the feature request form on the BuddyBoss contact page.
Root cause: By design, deleting forum discussions is limited to site admins in BuddyBoss forums on web and app.

## Customer note
Thanked for the clarification but said they are not happy with the limitation and asked for a workaround for web and app.
