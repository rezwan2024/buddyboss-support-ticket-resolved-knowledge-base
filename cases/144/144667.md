## Debugging steps
1. Confirmed registration works with Offload Media deactivated and fails with it active.
2. Ruled out: Remove Local Media, WordPress Media Library offloading and Serve from custom domain, all were off.
3. Disabled BuddyBoss reCAPTCHA for registration with Offload Media active: registration went through, so the reCAPTCHA check was failing.

## Solution
Re-enable BuddyBoss reCAPTCHA v3 for registration and lower the score threshold (for example from 0.5 to 0.3) in the BuddyBoss reCAPTCHA settings. If it still fails, switch to reCAPTCHA v2 checkbox, or turn off BuddyBoss reCAPTCHA and use the security plugin's registration CAPTCHA instead.
Root cause: reCAPTCHA v3 scored valid registrations below the threshold with the Offload Media and Cloudflare setup, so verification failed.
