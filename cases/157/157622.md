## Debugging steps
1. Ruled out: debug.log only showed deprecation notices and missing script dependency warnings (such as bb-topics-manager), none related to the error.
2. Reproduced: profile > Membership tab > Change Plan > select any paid plan > Select Plan. The checkout page loads and stops rendering at the payment step.
3. Ruled out: user-specific cause. Same failure from the admin account, another member account and a support account. Free plans not affected. Logged-out visitors see "unauthorized" on plan click, which is expected.
4. Used Query Monitor on the checkout page to capture the fatal error: the BbmsStripeTaxIntegration class is missing.
5. Development confirmed files the checkout code depends on were left out of the 1.14.1 plugin package, so all paid Stripe checkouts fail. A clean install without a connected payment gateway does not show it.

## Solution
Update BuddyBoss Membership to 1.14.3 or later (Dashboard > Updates or Plugins > Installed Plugins). Then click Connect with Stripe under Memberships > Settings > Payments again and run a test checkout in Stripe test mode.
Root cause: the 1.14.1 package did not include the Stripe tax integration class that the order quote builder calls while building the Stripe payment step.
