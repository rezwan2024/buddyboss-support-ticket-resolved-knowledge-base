## Debugging steps
1. Checked the subscription in the account: the license was still inside its grace period, so no renewal was needed.
2. Asked the customer to clear the site cache and any CDN or firewall cache, and to save Permalinks once.
3. Asked the customer to disconnect and reconnect the license in BuddyBoss App > Connect with the App ID and App Key from My Account > Subscriptions > Apps > Manage.
4. Ruled out: cache clear and reconnect from the customer side did not change the expired status.
5. Checked the site directly and found the old expired license status was held in the object cache.

## Solution
Updated the BuddyBoss App plugin, then cleared both the LiteSpeed cache and the object cache so the site read the current license status. Then submitted a new Android release build request.
Root cause: the object cache kept an old expired license status, which blocked the plugin update.

## Customer note
Said it is working now.
