## Debugging steps
1. Checked how push notification and email language is chosen: templates are translatable, but the language is not set per recipient.
2. Confirmed notifications use the site default locale at send time, not the language the user picked in the app.
3. Confirmed there is currently no per-user language option for push notifications.

## Solution
Workaround: keep notification text short and neutral, or include both languages in the text. Turn off unneeded notification types in the BuddyBoss App push notification settings, or disable the Push Notifications component in the BuddyBoss App settings to stop all app push notifications.
Root cause: Push notifications are sent in the site default locale at send time; the app language is stored on the device, not against the WordPress user.
