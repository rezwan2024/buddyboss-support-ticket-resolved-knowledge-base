## Debugging steps
1. Checked the update notice in WordPress Plugins, which blamed the license for the blocked update.
2. Ruled out: license problem. The license was connected correctly in BuddyBoss > License on the site.
3. Found a temporary block on the BuddyBoss update server that stops automatic updates on some sites.

## Solution
Workaround: download the latest BuddyBoss Platform zip from the BuddyBoss account dashboard, then go to Plugins > Add New Plugin > Upload Plugin, install it and click "Replace current with uploaded". Settings and content are kept. Questions about extra license time on a plan go to the Billing team in a new ticket.
Root cause: a temporary block on the update server stopped automatic updates for the site, not an invalid license.

## Customer note
Asked the team to do the update for them because the live site is large, and said the site still asks to activate the license.
