## Debugging steps
1. Compared the Tutor LMS My Courses page with BuddyBoss Theme active and with a default WordPress theme: broken only with BuddyBoss Theme.
2. Ruled out: CSS not loading. Both Tutor LMS and BuddyBoss stylesheets load.
3. Checked the Tutor LMS template overrides in BuddyBoss Theme (tutor/dashboard.php and the tutor/dashboard/ folder): they were built for the Tutor LMS 3.x structure, while Tutor LMS 4.x rebuilt its dashboard and course pages.
4. Matched to a known theme issue already fixed by the development team.

## Solution
Update BuddyBoss Theme to 2.22.4 or later, which adds full Tutor LMS 4.x support (dashboard, My Courses, course pages, lessons, profile and group course tabs). No custom CSS needed.
Workaround until updating: roll Tutor LMS and Tutor LMS Pro back to their matching latest 3.x versions.
Root cause: BuddyBoss Theme 2.22.3 Tutor LMS template overrides used the old Tutor LMS 3.x markup, which does not match Tutor LMS 4.x.
