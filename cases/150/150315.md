## Debugging steps
1. Added the bbapp_remote_get_args snippet that raises the timeout to 60 seconds for App Center requests and cleared all caches: the upload page stayed blank.
2. Ruled out: security and caching plugins (Wordfence, object cache), .htaccess, cURL missing, outdated CA bundle and outbound firewall rules.
3. Ruled out: the App Center side. Developer debugging showed the POST request reached App Center and completed in about 17 seconds.
4. Debug logging added in the plugin gave no output, so OPcache, Wordfence and Cloudflare rules were checked next.
5. Found a file in the custom theme that forced a 10 second cap on every outgoing HTTP request, so the App Center request was cancelled silently and the plugin showed an empty table.

## Solution
Added a small must-use plugin in wp-content/mu-plugins that allows a longer timeout for App Center requests only, so every other request keeps the theme's 10 second limit and a theme update cannot undo the fix. Editing the theme or raising the global timeout also works but was avoided.
Root cause: a site-wide HTTP timeout override hidden in the custom theme cancelled App Center requests before any data returned.
