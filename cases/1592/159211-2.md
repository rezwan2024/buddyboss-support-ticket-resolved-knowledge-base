## Debugging steps
1. Noticed the issue right after enabling the ReadyLaunch course template.
2. Compared the course page with the editor: the background color set on the course and the custom fonts were replaced by ReadyLaunch default styles.

## Solution
Workaround: dequeue the conflicting ReadyLaunch scripts/styles on course pages (with wp_dequeue_script / wp_dequeue_style added through a code snippet plugin) so the site's custom fonts and colors apply again.
Root cause: the ReadyLaunch course template loads its own assets, which override the site's custom fonts and colors.
