## Debugging steps
1. Checked BuddyBoss App settings and LearnDash quiz settings for an option that controls the highlight. None exists.
2. Ruled out: plugin conflict. The highlight stayed on a staging site running only BuddyBoss, MemberPress and LearnDash.
3. Reproduced the same yellow highlight on clean dev apps on both iOS and Android.
4. Confirmed with the team that it is the default quiz interface of the Next Gen app, present since the first test mode install.

## Solution
No fix. The yellow highlight on quiz answers is intended default styling of the Next Gen app quiz interface, and there is no setting in the app or LearnDash to disable it. Logged as product feedback for a future option.
Root cause: by-design default quiz styling in the Next Gen app.

## Customer note
Questioned why it was added, then thanked the team for logging the feedback.
