## Debugging steps
1. Customer read "App Core Version" on the app build screen as the BuddyBoss App plugin version.
2. Ruled out: App Core Version is the app core of the build, not the BuddyBoss App plugin version on the site.

## Solution
No fix, this is a feature request: show the BuddyBoss App plugin version on the build screen so it is clear which plugin version a build came from. Pass it to the product team.
Root cause: the build screen shows only the App Core Version, which is easy to mistake for the plugin version.

## Customer note
Asked for the BuddyBoss App version to be shown on the build screen.
