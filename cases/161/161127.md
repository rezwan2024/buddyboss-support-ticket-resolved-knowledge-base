## Debugging steps
1. Ruled out: license key problem, Platform Pro and the other plugins updated fine with the new key.
2. Explained that Platform and Platform Pro are both required, Pro extends Platform and does not replace it.
3. Compared the installed Platform version with the latest on the account Downloads page: both 3.6.1.
4. Found the update notice offered version 2.14.4, which is older than the installed version.

## Solution
No update was needed, the installed Platform version was already the latest. The notice came from stale saved update data. To clear it, go to BuddyBoss Dashboard > License Keys, click Save Changes, then Dashboard > Updates and click Check Again a few times. Do not click "update now" while it points to the older version. If a real update fails, download the latest zip from the account Downloads page and upload it via Plugins > Add New > Upload Plugin > Replace current with uploaded.
Root cause: cached update data from the old license setup offered an older Platform version without a valid download link.
