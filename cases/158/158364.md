## Debugging steps
1. Customer wanted the site viewable by everyone while posting and commenting stay limited to logged in members, and could not find the setting where it used to be.
2. Checked where the privacy option lives in the new BuddyBoss admin: it moved, it was not removed.
3. Ruled out: extra setup for posting rights. Viewing is open by default and posting or commenting already require an account.

## Solution
Go to BuddyBoss > Settings > Advanced Component > Settings > Privacy and untick Private Website. The new admin saves on change, so there is no Save button.
Test in an incognito window as a logged out visitor, and clear any caching plugin or CDN cache first.
Root cause: the Private Website option moved to a new place in the new BuddyBoss admin.
