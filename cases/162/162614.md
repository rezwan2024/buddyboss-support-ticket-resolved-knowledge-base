## Debugging steps
1. Checked the screenshots: the Tutor courses block shows as an unsupported block type, and opening a Tutor LMS course from the image carousel ends on an error screen.
2. Reproduced on a Next Gen app with Tutor LMS active, with a Tutor courses block and a LearnDash courses block on the same home screen.
3. Ruled out: site setup. The Tutor block showed the same unsupported message, while LearnDash courses loaded normally.
4. Confirmed in the official Next Gen announcement that Next Gen does not support Tutor LMS yet, while the Classic React Native app does.

## Solution
Not supported yet: Next Gen has no course screens for Tutor LMS. Use LearnDash with Next Gen, or test Tutor LMS Pro with a Classic app build, which is included in the BuddyBoss App subscription.
If staying on Next Gen, remove the Tutor courses block from the app home screen so members do not see the unsupported block message.
Root cause: The BuddyBoss App Next Gen does not support Tutor LMS yet; the Tutor LMS integration covers only the Platform and Theme on the website side.

## Customer note
Said no problem, LearnDash stays their choice, and thanked the team.
