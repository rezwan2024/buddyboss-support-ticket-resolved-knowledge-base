## Debugging steps
1. Checked the member profile on desktop: name showed on one line.
2. Customer reported it on phone, tablet and a very large screen; the app profile looked fine, the web profile still split the name.
3. Ruled out: expected responsive wrap of a long title. The word itself was broken, not moved whole to the next line.
4. Reproduced on a clean site: a long single-word name breaks onto a second line in the mobile web view. Escalated as a product bug.

## Solution
Fixed in a later release. Update the BuddyBoss Theme and BuddyBoss Platform plugin to the latest versions, then clear all caches and test again.
Root cause: profile header name styling allowed a long single word to break mid-word instead of wrapping as a whole.
