## Debugging steps
1. Checked the account: the license was enabled and showed 1 of 1 sites activated.
2. Ruled out: a problem with the license itself.
3. Checked installed versions on the site: Platform 2.14.0, Platform Pro 2.10.0 and Theme 2.6.30, several major versions behind (latest at the time Platform 3.4.3, Pro 3.3.0, Theme 2.14.4).
4. Found that the old builds cannot validate against the current licensing system and are not offered automatic updates because of the large version gap.

## Solution
Take a full backup (or use staging), download the latest ZIPs from the BuddyBoss account downloads page, and upload them with Replace current with uploaded in this order: Platform, then Platform Pro, then Theme.
Then go to BuddyBoss > Settings > Licenses, deactivate and reactivate the license so the notices clear. Review release notes and any custom code or child theme templates after such a large jump.
Root cause: very old Platform, Platform Pro and Theme builds could not validate the active license against the current licensing system.
