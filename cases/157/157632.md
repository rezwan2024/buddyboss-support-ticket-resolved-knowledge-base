## Debugging steps
1. Asked for the failed upload ID and build ID.
2. Ruled out: build failure. The iOS build itself showed as completed, so only the upload step to Apple was failing.
3. Asked for site admin access to check the app settings; first login attempt failed because the customer had not saved the new user, then it worked.
4. Asked for the exact steps to reproduce; the customer confirmed the error appears when uploading the finished build to Apple.

## Solution
No change was made on the site. The customer retried the upload of the finished build to Apple and it went through.
Workaround: when an iOS build is completed but the Build Upload request fails with "Unknown error", retry the upload before deeper debugging.
Root cause: not identified; the upload error was temporary and did not come back on retry.

## Customer note
Said everything works now and the ticket can be closed.
