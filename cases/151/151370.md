## Debugging steps
1. Build log showed a signing error (PKCS12_parse: mac verify failure), so the signing certificate and provisioning profiles were deleted and regenerated several times. Test build still failed.
2. Next log failed at the icon fetch step (Terminated: 15) with the custom code package loaded. Ruled out: custom code, the agency team checked it and the release build with the same code worked.
3. Ruled out: hosting firewall changes, the host confirmed nothing changed. Updated BuddyBoss Platform Pro and the BuddyBoss App plugin. Test build still failed.
4. Dev team found the build package upload from the site to the build server hit a fixed timeout and was cut off part way, so the rest of the files arrived empty and the build failed later on whichever empty file it hit first.

## Solution
Fixed in a BuddyBoss App plugin release. Update the BuddyBoss App plugin to the latest version, then send a new iOS test build request. Nothing to change on hosting or firewall, and no need to regenerate certificates again.
Root cause: the build package upload used a fixed timeout that cut off large uploads, leaving empty files that broke the build at random steps.
