## Debugging steps
1. Compared the options the customer saw on the BuddyBoss Theme demo with the ReadyLaunch settings.
2. Ruled out: missing features. ReadyLaunch has the profile options, only in a different place than the Theme Options.

## Solution
Use the ReadyLaunch settings under BuddyBoss > Settings > Appearance to set the profile header layout, the elements shown on the profile header and the cover image settings.
Root cause: the customer looked for the BuddyBoss Theme Options, but ReadyLaunch keeps its profile settings in the Appearance settings.
