## Debugging steps
1. Checked the Next Gen build permissions in App Bundle Explorer: it has android.permission.ACCESS_ADSERVICES_AD_ID but not com.google.android.gms.permission.AD_ID, so "Yes" fails with a missing permission error.
2. Confirmed the default Next Gen app runs no ads and does not need the advertising ID, so "No" is the correct declaration.
3. Ruled out: refreshing the console and re-saving the "No" declaration, the error stayed on Publishing overview.
4. Google Play checks the declaration against every active build on every track, not only the new upload. An older Classic build still active on another track (here Internal testing) still had the AD_ID permission and conflicted with "No".

## Solution
Keep the Advertising ID declaration on "No". Find every track (Production, Internal, Closed, Open testing) that still has an older Classic build active, create a new release there with the Next Gen bundle from the App Bundle Library and publish it to replace the old build. The error then clears and Submit for review is enabled, with no need for "Turn off release errors".
Root cause: an older Classic build with the AD_ID permission was still active on the Internal testing track and conflicted with the "No" declaration needed for the Next Gen build.

## Customer note
Said it was resolved by replacing the old Internal testing build, kept "No", and thanked the team.
