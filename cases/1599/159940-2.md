## Debugging steps
1. Confirmed the count is the bell in the BuddyBoss admin Inbox under BuddyBoss > Settings, not member notifications on the front end.
2. Dismissed one item: the count dropped at once in the browser, then returned after a reload.
3. Tested the same action on a clean site: the dismissed item moves to the Read tab but stays listed under All.
4. Checked with the development team how the Inbox stores dismissed items.

## Solution
No fix. The admin Inbox never deletes notifications; dismissed items are only marked read and stay in the total, and there is no option to remove them. An improvement request was logged to allow clearing or hiding dismissed notifications.
Root cause: by design, the shared admin Inbox (also used by other plugins such as MemberPress) keeps every notification and has no delete option.
