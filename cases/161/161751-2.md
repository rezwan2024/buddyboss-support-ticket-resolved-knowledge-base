## Debugging steps
1. Customer looked for quiz feedback in LearnDash settings, but the quizzes were created in BB Courses.
2. Ruled out: LearnDash settings. They have no effect on BB Courses quizzes.
3. Checked whether the Quizzes menu shows under BB Courses. If it is missing, the Course Quizzes add-on is not installed.

## Solution
Feedback is set per question: BB Courses > Quizzes, edit the quiz, select a question block such as Multiple Choice and add the feedback shown on an incorrect answer in its settings.
To let learners review results, go to BB Courses > Courses, edit the course, open the Settings tab and turn on Show Question Results and Show Question Answers.
If Quizzes is missing under BB Courses, download the BuddyBoss Course Quizzes add-on from My Account > Downloads, upload it in Plugins > Add New Plugin > Upload Plugin and activate it.
Root cause: BB Courses quiz feedback is set in each question's block settings, not in LearnDash settings.
