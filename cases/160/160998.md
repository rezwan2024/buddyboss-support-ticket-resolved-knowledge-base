## Debugging steps
1. Ruled out: the release itself; Platform 3.6.1, Platform Pro 3.3.3 and Theme 2.22.3 opened groups normally on a clean site.
2. Got the PHP error trace for a failing group page from the site.
3. Customer found group pages load again with Yoast SEO deactivated.
4. Trace pointed to the Yoast compatibility step in BuddyBoss Sharing, which calls the Yoast class WPSEO_Frontend that current Yoast versions no longer provide.
5. Reproduced on test sites with BuddyBoss Sharing and Yoast SEO both active.

## Solution
Update BuddyBoss Sharing to v2.1.2 or later. Workaround until then: keep Yoast SEO active and temporarily deactivate BuddyBoss Sharing.
Root cause: Sharing's Yoast compatibility code relied on the removed Yoast class WPSEO_Frontend, causing a fatal error on group pages.

## Customer note
Said groups work again with Yoast deactivated but they need Yoast; no reply after the fix release.
