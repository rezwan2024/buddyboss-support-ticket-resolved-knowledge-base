## Debugging steps
1. Ruled out: Relevant Activity setting was off, so the main feed was not limited to certain members.
2. Ruled out: posts were set to Public, and the posts showed on the website feed, so the issue was app only.
3. Cleared the app API cache, app transients, the page cache plugin cache and PHP OPcache before testing.
4. Tested the latest app build (core 3.2.0) and the feed loaded with the posts; checked the About screen in the app on the devices matched the latest build.

## Solution
Clear the app caches: WP Admin > BuddyBoss App > Settings > API Caching > Purge All, and WP Admin > BuddyBoss App > Tools > Transients > Clear Transients. Also clear the site cache plugin and PHP OPcache. The feed loaded again on all devices.
Root cause: a cached API response from when the error happened was still being served to the app.
