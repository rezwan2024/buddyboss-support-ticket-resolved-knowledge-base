## Debugging steps
1. Checked the last digest run line in the admin Email Digest settings: the digest ran on schedule but processed 0 members and queued 0 emails.
2. Ruled out: admin setting. BuddyBoss Settings, Email Digest was enabled with Daily as the default frequency.
3. Checked the admin's own frontend profile, Settings, Notifications, Email digest: it was set to Off.
4. Confirmed the Default Frequency only applies to members who join after the digest is enabled. Existing members, admins included, stay on Off until they pick a digest option.

## Solution
On the frontend profile go to Settings, Notifications, Email digest, choose Daily digest and click Save Changes. Wait for a few new notifications, then use Send Test Digest, which sends a preview only to your own email.
Existing members must choose Daily or Weekly on their own profiles to receive the digest. The real digest goes out once a day from the send time set in admin, in batches.
Root cause: the member level digest setting was Off for existing members, so notifications were sent one by one and nothing was collected for the digest.
