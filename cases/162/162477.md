## Debugging steps
1. Reviewed the customer's screen recording of the login page on a phone.
2. Confirmed the BuddyBoss Theme has no built-in setting for the login image height on mobile, so the image shows shorter on small screens.
3. Ruled out: a desktop layout problem. Only screens 544px wide and below are affected.

## Solution
Add CSS to the login page only, through the BuddyBoss Child Theme functions.php (Appearance > Theme File Editor) or a code snippet plugin, then clear site and browser cache:
```php
add_action( 'login_enqueue_scripts', 'the_boss_custom_login_css' );
function the_boss_custom_login_css() {
    echo '<style type="text/css">
    @media (max-width: 544px) {
        body.login.login-split-page .login-split .login-split__entry { height: 275px; }
    }
    </style>';
}
```
Change 275px to the height you want, for example 400px. The desktop layout stays the same, and removing the code undoes the change. The BuddyBoss docs article "Increase the login page image height for mobile view" covers the same steps.
Root cause: the theme gives the split login image a fixed short height on mobile, and there is no setting to change it.
