## Debugging steps
1. The enrolled student count showed on each course in the Courses carousel on the app Home page, and it had been hidden before.
2. Checked the Courses block settings on the Home app page and found the Show Enrolled option.

## Solution
Go to BuddyBoss App > App Pages, open the Home page, select the Courses block, open the Block tab in the right sidebar, scroll to Settings, turn off Show Enrolled and save. No new build is needed, refresh the Home screen in the app.
If the Courses block is used on other app pages, turn off Show Enrolled on each block separately.
Root cause: the enrolled count is a per-block setting of the Courses block and is shown by default.
