## Debugging steps
1. Customer saw several PHP 8 deprecation notices in a query profiler, all coming from the bundled binary-driver library inside BuddyBoss Platform.
2. Checked whether the library was updated in the latest Platform release.

## Solution
Update BuddyBoss Platform to the latest version, where the bundled library was updated for PHP 8 compatibility. The notices are deprecation only and do not break any feature.
Root cause: Older bundled binary-driver library not written for PHP 8.

## Customer note
Said they updated to the latest versions; did not mention the warnings again.
