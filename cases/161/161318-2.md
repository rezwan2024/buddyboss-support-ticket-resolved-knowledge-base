## Debugging steps
1. Customer saw a newer child theme version listed but no update link on the add-ons page.
2. Confirmed the child theme was active and the parent BuddyBoss Theme was installed.

## Solution
No action needed. The BuddyBoss Child Theme is provided once as a safe place for customizations and does not get updates; keep it active and update only the parent BuddyBoss Theme, which does not remove child theme changes.
Root cause: expected behavior; the child theme is not an updatable product.
