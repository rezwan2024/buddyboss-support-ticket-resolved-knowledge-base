## Debugging steps
1. Reproduced the critical error when opening any item from the profile avatar dropdown menu.
2. Checked the PHP error log in a troubleshooting session that only affects the agent's login.
3. Error traced to the BuddyBoss Sharing plugin conflicting with Yoast SEO while a profile page loads.

## Solution
Workaround: deactivate only the BuddyBoss Sharing plugin until the fix is released. Profile menu pages then load normally. A fix is planned for an upcoming release.
Root cause: Known BuddyBoss Sharing bug that conflicts with Yoast SEO on profile pages.

## Customer note
Replied only that the site was cloned from another site and shared the original site for comparison, no feedback on the fix.
