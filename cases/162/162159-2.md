## Debugging steps
1. While applying a BuddyBoss Membership plugin patch over SFTP, reviewed the site's public web folder.
2. Found a private key file and several database dump files stored in the public folder.
3. Noted that files in the public folder can usually be opened from the web by anyone with the link.

## Solution
Move the private key file and database dump files outside the public web folder, or delete them if they are no longer needed. The hosting provider can do this if the site owner prefers.
Root cause: private and backup files were stored in the public web folder instead of a folder the web server does not serve.

## Customer note
Thanked the team and said the checkout issue was gone; did not mention the files.
