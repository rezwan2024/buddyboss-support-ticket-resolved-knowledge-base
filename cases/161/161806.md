## Debugging steps
1. Opened the app signup screen and confirmed Nickname shows as a required field.
2. Checked the display name format in the profile settings: it was set to First Name only.
3. Checked the Profile Name settings for the Display Name Fields options.

## Solution
Go to BuddyBoss > Settings > Member Profiles > Profile Name and turn off Nickname under Display Name Fields. Nickname then no longer shows on the signup form.
Root cause: Nickname was still turned on as a display name field, so it stayed required on registration although the display name uses First Name only.
