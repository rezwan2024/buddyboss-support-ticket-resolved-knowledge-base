## Debugging steps
1. Customer enabled BuddyBoss Memberships, made a new iOS build and saw no memberships section in the app and no membership choice at registration.
2. Checked the in-app products in the App settings: products were created correctly.
3. Found the Integration Type of each in-app product still set to Select, so no product was linked to a BuddyBoss Membership level.

## Solution
Edit one in-app product, set Integration Type to BuddyBoss Memberships and pick the membership level, save, then make a new Test App build and test the full purchase flow. Once it works, set up the other products the same way. To show products at sign-up, enable the option that requires an in-app purchase during registration; use Access Controls to limit app content by membership.
Root cause: there is no separate Memberships section in the app; memberships are sold through in-app products, and with Integration Type left on Select no membership is linked or assigned.
