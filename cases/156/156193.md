## Debugging steps
1. Customer checked a fresh install of Platform, Theme and the Courses add-on with LearnDash not installed.
2. Confirmed the add-on registers only four post types: course, lesson, quiz and assignment. No certificate post type or certificate table.
3. Confirmed the student view at 100% completion shows only Course Overview and Grades, with no certificate.
4. Checked with the product and development teams: certificates are not built into BuddyBoss Courses yet.

## Solution
Expected behavior, not a bug. BuddyBoss Courses has no certificate feature yet. It is noted for a future release with no date or version shared. Certificate Builder, Verified Certificates and Certification Renewals come with the LearnDash integration, so use LearnDash if certificates are needed now. Watch the Courses release notes for when certificates ship.
Root cause: certificates are not implemented in the BuddyBoss Courses add-on yet. The feature is only on the roadmap.
