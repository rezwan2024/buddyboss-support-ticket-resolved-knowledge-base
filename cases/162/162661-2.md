## Debugging steps
1. Confirmed expected behaviour: each discussion tag link should open its tag page listing all discussions with that tag.
2. Found only some tags failed while others worked.
3. Ruled out: a broken tag record; deleting and recreating the tag with the same name did not help.
4. Found the tag links under each discussion are built from the tag name; when the name has extra text such as a word in parentheses, the link no longer matches the tag page and ends up empty, so the click reloads the same page.

## Solution
Added a small code snippet with a code snippet plugin that finds the correct tag page by the tag name as a fallback, so tag names can stay as they are. Clear site cache after adding it. A workaround is to remove the extra text from the tag names.
Root cause: the theme builds discussion tag links from the tag name, and names with extra text in parentheses produce an empty link.
