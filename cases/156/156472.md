## Debugging steps
1. Went to Users > Pending Signups, clicked Activate and then Confirm as an administrator. The error appeared every time.
2. Checked the BuddyBoss reCAPTCHA integration. It was connected, using v3 with a 0.5 score threshold, and enabled for Login, Registration, Reset Password and Account Activation.
3. Turned off the reCAPTCHA integration and activated the same pending account again. It worked right away, so the problem is the reCAPTCHA check running on the admin activation.
4. Reproduced the same error on a clean dev site with the latest versions and escalated it as a bug.

## Solution
Update BuddyBoss Platform to v3.7.0 or later, where this is fixed.
Workaround before the update: turn off the BuddyBoss reCAPTCHA integration, activate the pending account manually, then turn reCAPTCHA back on.
Root cause: the Account Activation reCAPTCHA check also ran when an admin activated an account from WordPress admin, where there is no frontend reCAPTCHA token.
