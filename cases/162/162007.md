## Debugging steps
1. Ruled out: outdated versions. Updated to BuddyBoss App plugin 3.2.10 and Platform 3.6.2, new iOS test build still clipped.
2. Ruled out: device text settings. Larger Text, Bold Text and other Display and Text Size options were off.
3. Checked BuddyBoss App > Installed Fonts: the custom font had Font Scale 108, Montserrat had 100. Setting it to 100 only reduced the clipping.
4. Uploaded the same font files on a test site and reproduced the clipping in a test build. Montserrat showed the search field correctly.
5. Ruled out: a custom copy of the font with line spacing reduced from 1.81 to 1.35 times the font size still sat low in the field.

## Solution
Switch the app body font to a font with standard line metrics, such as Montserrat, and keep Font Scale at 100 in Installed Fonts, then request a new build. This is a workaround. Another option is a font copy with line spacing close to 1.22 times the font size. Making the search field center text for tall line metrics is a feature request.
Root cause: the Next Gen search field has a fixed height designed for standard line metrics and a Font Scale of 100, so fonts with tall line boxes, or a scale above 100, push the text down and clip it.

## Customer note
Said the search field is fine after switching to Montserrat at Font Scale 100 and thanked the team.
