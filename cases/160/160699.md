## Debugging steps
1. Opened the scanner entry: it listed BuddyBoss Platform versions up to and including 3.1.0, was marked not yet verified and had no fixed version recorded.
2. Confirmed with the development team: the main issue was fixed in Platform 3.5.0, a related one in 3.6.0, and 3.6.0 is not affected.
3. Asked the customer for the installed version from the Plugins page. It showed 3.6.0.
4. Ruled out: a real problem on the site. The alert came only from the scanner database, which had not yet recorded the fixed version.

## Solution
Update BuddyBoss Platform to 3.6.0 or later from Dashboard > Plugins, with a backup taken first. On 3.6.0 or later, nothing else needs to change.
The scanner can keep flagging the plugin and show "No known fix" until its database records the fixed version. The fix version was sent to the scanner database for validation.
Root cause: the scanner database entry had no fixed version recorded, so current installs were still flagged.
