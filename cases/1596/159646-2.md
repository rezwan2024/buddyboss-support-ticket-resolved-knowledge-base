## Debugging steps
1. Updated the BuddyBoss App plugin to 3.2.6; the migration showed the duplicate column error.
2. Checked the database: the background process logs table was not created.
3. Noted separate PHP warnings Attempt to read property "ID"/"post_type" on null in AccessControls.php when editing In-App Purchases products.

## Solution
Deactivate and reactivate the BuddyBoss App plugin so the activation routine creates the missing background process logs table. This is a workaround. The AccessControls warnings were not addressed.
Root cause: the 3.2.6 migration stopped at an already existing column and skipped the rest of the table creation.

## Customer note
Said deactivating and reactivating the plugin created the missing table; no further reply.
