## Debugging steps
1. Updated BuddyBoss Platform (3.4.4 to 3.5.1), Platform Pro (3.3.1 to 3.3.2) and the LearnDash add-on, then cleared cache.
2. Ruled out: outdated plugin versions, the feed still kept loading after the updates.
3. Tested on a staging copy for a plugin conflict and checked the error behind the feed AJAX request.
4. Found the feed crashed on one Spanish translation string where a placeholder (such as %s or %d) had been translated by mistake.

## Solution
In Loco Translate, open the BuddyBoss Platform Spanish translation, use the custom translation file, find the string with the broken placeholder and restore the placeholder exactly as in the English source. Save, then clear the caching plugin cache and reload the activity page.
Root cause: a translated string with a wrong or missing placeholder makes the PHP format function throw a fatal error on newer PHP versions, so the activity AJAX request fails and the spinner never stops.
