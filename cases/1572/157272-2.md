## Debugging steps
1. Checked the push notification log: deliveries failed with SenderId mismatch.
2. Confirmed the Firebase project used in the app settings was not the one the installed app was built with (customer had created a new Firebase project).
3. Requested a new iOS and Android build after the Firebase configuration was corrected.

## Solution
Reconfigure Firebase for push notifications following the BuddyBoss Firebase guide, keeping one Firebase project for both iOS and Android with its config files uploaded in the app settings. Then request a new build and install it on the devices, so they register tokens with the current Firebase project.
Root cause: device tokens were registered under a different Firebase sender than the one configured in the app settings.
