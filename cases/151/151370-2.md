## Debugging steps
1. Checked the iOS build log on the build server: E016, no Apple Distribution certificate found for the team.
2. Same log showed E017, the release provisioning profile had expired.

## Solution
In the Apple Developer portal, revoke or delete the existing iOS Distribution certificate. In WordPress go to BuddyBoss App > Configure > iOS Settings > Signing Certificates, untick Automatically generate signing certificate, save, tick it again and save to regenerate the certificates. On the same page enable Automatically generate provisioning profiles and regenerate them, then request a new iOS build. Docs: how to resolve build error codes E002, E016, E017.
Root cause: the Apple Distribution certificate was missing or invalid and the release provisioning profile had expired.
