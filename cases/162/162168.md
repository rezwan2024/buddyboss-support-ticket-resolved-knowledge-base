## Debugging steps
1. Confirmed the Sharing button shows on activity posts on web but not in the Next Gen app.
2. Ruled out: a product bug. On a test setup with the Next Gen app, the Sharing button showed in both the app and on web.
3. Checked that the BuddyBoss Add-ons plugin is installed and active, and that BuddyBoss Platform and BuddyBoss App are on the latest versions.
4. Cleared site, server and CDN caching.

## Solution
Install and activate the BuddyBoss Add-ons plugin, update BuddyBoss Platform and BuddyBoss App to the latest versions, then create a new app build and test with it. The new build showed the Sharing button.
Root cause: the app build was older than the plugin updates, so it did not include the Sharing button.

## Customer note
Said the Sharing button shows after the new build and thanked the team.
