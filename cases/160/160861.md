## Debugging steps
1. Reproduced: posting with "My profile" or "All members" visibility freezes on the first attempt, the post only goes through after a page refresh.
2. Ruled out: Public visibility and group posts work normally, PHP error log is empty.
3. Browser console shows the null 'id' TypeError from bb-activity-post-feature-image.js, which belongs to Platform Pro (versioned separately from Platform, so a 3.3.2 stamp next to Platform 3.6.0 is expected).
4. Confirmed it hits regular members only, not administrators, with "Post Feature Image" enabled under BuddyBoss > Settings > Activity.

## Solution
Update BuddyBoss Platform Pro to 3.3.3 or later, which contains the fix. Before the update, refreshing the page was the only workaround.
Root cause: Platform Pro bug where the post feature image script read a value that is empty for non-public visibility posts by regular members.
