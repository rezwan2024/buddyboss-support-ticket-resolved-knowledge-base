## Debugging steps
1. Reproduced on the customer's iOS build: descriptions show in some places and are missing in others across activities, groups and the gallery.
2. Ruled out: missing data. The website shows the descriptions correctly for the same photos.
3. Ruled out: app code alone. The same images showed descriptions correctly in a development app.
4. Cleared the LiteSpeed cache and object cache on the site, then the descriptions showed in the gallery of the customer's build.

## Solution
Clear the BuddyBoss App API cache, the LiteSpeed Cache plugin cache and the object cache on the site, then fully close and reopen the app. Clearing caches on the phone does not help.
Root cause: suspected stale activity data cached on the server and served to the app, not confirmed.

## Customer note
Said the first multi-image activity now looks right, but the next activities still have missing image descriptions.
