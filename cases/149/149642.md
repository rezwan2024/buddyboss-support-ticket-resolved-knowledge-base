## Debugging steps
1. Confirmed the offloaded profile photo and cover photo display correctly in the header, the member profile and across the community.
2. Ruled out: caching. Clearing the page cache plugin and the browser cache did not help.
3. Ruled out: stale status. Running the repair tool to re-sync the Profile Completion widget profile photo status did not help.
4. Ruled out: JavaScript errors on the widget.
5. Reproduced as a known bug: when avatars and covers are offloaded and the local copies are removed, the widget does not detect the photo.

## Solution
Update BuddyBoss Platform to v3.6.1 or later and Offload Media to v2.1.4 or later, where the bug is fixed.
Root cause: the Profile Completion widget checked for the local avatar file, so it missed avatars that only exist in offloaded storage.
