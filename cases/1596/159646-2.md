## Debugging steps
1. Updated the BuddyBoss App plugin to 3.2.6 and the migration showed the database error Duplicate column name 'app_product_id'.
2. Checked the database: the background process logs table was not created.
3. Deactivated and reactivated the BuddyBoss App plugin.

## Solution
Deactivate and then reactivate the BuddyBoss App plugin. Activation runs the table setup again and creates the missing background process logs table. Take a backup first.
Root cause: the 3.2.6 migration stopped on a column that already existed, so the later step that creates the new table never ran.
