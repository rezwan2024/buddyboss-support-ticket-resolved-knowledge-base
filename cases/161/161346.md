## Debugging steps
1. Customer built a minimal probe from the official custom-code template (startup alerts and a label in the Create Post composer) on a custom Git branch.
2. Ruled out: wrong build installed. The correct Next Gen test build was installed and running, but none of the probe output appeared.
3. Asked where the custom code lived: website side (custom plugin) or only the custom Git repository connected through the BuddyBoss App plugin. The website code was separate and worked on the web.
4. App development team confirmed how Next Gen loads custom code.

## Solution
Not a build or code error. Custom development is not open for the Next Gen app yet. The custom-code template (index.js, applyCustomCode) is for the Classic app, which runs on React Native. Next Gen is built on Flutter, so custom JavaScript from the Git repository is never loaded or executed. For custom Next Gen features, refer the customer to the BuddyBoss Agency team. For new built-in features, such as native livestreaming, point them to the feature request form.
Root cause: The App Core 3.2.4 release notes wrongly mentioned new Next Gen developer hooks. Next Gen does not support the React Native custom-code framework.

## Customer note
Thanked the team for explaining the Next Gen custom code limits and sent a native livestreaming feature request.
