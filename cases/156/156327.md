## Debugging steps
1. Customer could not turn on Like/Reactions, Polls, Pin Posts, Like Buttons and Social Logins in BuddyBoss settings.
2. Ruled out: Platform Pro missing. Platform Pro and the other BuddyBoss add-ons were installed and active.
3. BuddyBoss > Add-ons listed the "BuddyBoss Addons" plugin as Not Installed.

## Solution
Download the BuddyBoss Addons plugin from the BuddyBoss account, then install and activate it. After that the feature settings can be turned on.
Root cause: these features need the BuddyBoss Addons plugin, which was not installed.

## Customer note
Asked if the BuddyBoss Addons plugin was the one to install, then no reply after the agent confirmed it.
