## Debugging steps
1. Checked the BuddyBoss App Connect tab: the licence was active (Full licence) with a future expiry date, so the extension had been applied.
2. Ruled out: real expiry. Recent iOS builds in Build History had completed successfully.
3. Sent a new build from the Build History page, and it went through and started generating.

## Solution
The expired message on the Request Build screen was a stale licence status, not a real block. Workaround: request builds from App > Build > Build History, then click the Build tab at the top of that page.
To clear the message, clear the server cache, then disconnect and reconnect the app on the Connect tab.
Root cause: the Request Build page showed a cached, outdated licence status after the licence was extended.
