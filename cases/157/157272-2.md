## Debugging steps
1. Checked Build History for failed builds after the customer changed Firebase settings.
2. Requested a new iOS and Android build from the support side.
3. Confirmed both builds show Completed in Build History and asked the customer to install them with the Install buttons.

## Solution
Request a fresh iOS and Android build once the Firebase settings are in place, then install both from Build History.
Root cause: not stated in the ticket; the fresh build request completed without further changes.
