## Debugging steps
1. Checked the iOS build log in the App dashboard and on the App Center server: the build stopped at the signing step.
2. Found the iOS distribution provisioning profile had expired and the Apple Distribution certificate for the team could not be found.
3. Ruled out: nothing in the app itself caused the failure.
4. Checked BuddyBoss App > Configure > iOS Settings: the Apple Developer account was not connected, so the certificate and profile could not be generated automatically.

## Solution
Connect the Apple Developer account: in App Store Connect > Users and Access > Keys, generate an API key and download the .p8 file, then upload it in BuddyBoss App > Configure > iOS Settings under Apple API Key with the Issuer ID and Key ID, and save.
Then regenerate the certificate and provisioning profile together: untick the generate option for both and save, delete both entries and save, tick generate for both again and save, then request a new iOS build. Renewing only one of them gives the same failure.
Root cause: expired provisioning profile and missing distribution certificate that could not be renewed because the Apple account was not connected.
