## Debugging steps
1. Cleared all site caches (page, object, OPcache, App plugin API cache, transients) and re-saved permalinks. The error went away briefly but came back.
2. Narrowed it down: only posts in certain categories failed. Blog listing and category endpoints still worked.
3. Ruled out: custom blog plugins, membership restrictions and category settings. Deactivating them and purging cache did not help.
4. Checked the REST API response for a failing single post: it returned HTTP 200 with content type application/json, but the JSON did not parse because an Elementor style element was printed before it.

## Solution
In Elementor settings, set CSS Print Method to External File, regenerate the Elementor CSS files, then clear the site cache. The blog sliders and posts then loaded in the app again.
Root cause: Elementor printed inline CSS before the JSON body of the single post REST API response, so the app could not parse it.
