## Debugging steps
1. Checked App Pages and the Tab Bar menu for the member group: Home page was the first tab and set up correctly.
2. Reproduced on a new build: Courses, Activity and Discussions blocks wait up to 30 seconds, show "An unknown error occurred", then load on Try again.
3. Ruled out: caching plugin, the specific page (the same blocks failed on a new test page), and a login session manager plugin.
4. Ruled out: app content and settings. The block API endpoints returned data correctly within seconds when called directly with a member login, and staging with all plugins active worked.
5. Ran a plugin conflict test on the live site, one plugin at a time, keeping BuddyBoss and MemberPress active, and found Elementor adding its CSS into the data the app receives.

## Solution
Update the free Elementor plugin to its latest version. Older versions inject CSS into the API responses when the Internal CSS Embedding option is in use. After the update, the Home blocks load on the first open.
Root cause: an outdated Elementor version added inline CSS to the REST responses and broke the data the Home blocks need.
