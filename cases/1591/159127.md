## Debugging steps
1. Generated a fresh app build and tested video download and playback. Still failing on both Classic and Next Gen test apps.
2. Ruled out: server firewall, ModSecurity and security plugin blocking. Hosting logs showed no blocked app requests, even after allowing the BuddyBossBot user agent.
3. Ruled out: Cloudflare proxy. Turning the proxy off did not change anything.
4. Found the Vimeo videos had been moved to a different Vimeo account. Video IDs and URLs stayed the same, so streaming still worked but offline downloads did not.

## Solution
Reset the Vimeo integration so it is connected to the Vimeo account that now owns the videos. Then download the videos again in the app and test playback.
Root cause: the Vimeo integration was still linked to the old Vimeo account, so offline downloads of the transferred videos failed to play.
