## Debugging steps
1. Asked for a screen recording of the free and paid sign up flows in a private window to see where the duplicate forms appear.
2. Found three registration systems running at once: the membership plugin form, the WooCommerce login and register block on the my-account page, and a BuddyBoss registration form.
3. Found the registration form shortcode pasted into the login page, so login and register pages showed the same fields.
4. Found the membership plugin redirecting new users to the BuddyBoss Activate page, which asks for a key the member never receives and was restricted to members only.

## Solution
Removed the registration shortcode from the login page so it only shows the membership plugin login form. In BuddyBoss > Settings > Pages (Registration), set BuddyBoss to use the custom registration page so there is one registration route. Changed the membership plugin's after-registration redirect from the BuddyBoss Activate page to the login page. Optional: added a profile tab linking the plugin's subscriptions and payments pages inside the BuddyBoss profile.
Root cause: competing registration systems plus a redirect to the BuddyBoss activation page for accounts not created by BuddyBoss.
