## Debugging steps
1. Confirmed the critical error shows only on the activity feed, single groups and forum discussions, while other pages load normally.
2. Ruled out: the known BuddyBoss Sharing and Yoast SEO conflict, since neither plugin was installed on the site.
3. Logged in as admin and reproduced the error on the news feed to read the fatal error details.
4. Found the error comes from the saved notification settings option: one entry is in a format the Platform code does not expect, and the page stops when the forum reply form loads.

## Solution
Workaround until the Platform fix is released: add this with a code snippet plugin (safer than the theme's functions.php, which a theme update replaces). Remove it once the Platform update includes the fix.
```php
add_filter( 'option_bb_enabled_notification', function ( $value ) {
	if ( ! is_array( $value ) ) {
		return array();
	}
	return array_filter( $value, function ( $entry ) {
		return is_array( $entry ) && array_key_exists( 'main', $entry );
	} );
} );
```
Root cause: a malformed entry in the saved bb_enabled_notification option (known Platform bug) triggers a fatal error when the forum reply form loads.

## Customer note
Said it worked, moved the code to a snippets plugin and thanked the team.
