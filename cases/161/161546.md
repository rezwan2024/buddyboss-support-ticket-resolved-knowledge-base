## Debugging steps
1. Checked the latest builds in AppCenter: the Android build had completed and was ready for Google Play Console, only the iOS build had failed.
2. Reviewed the iOS build log: the build stopped within a few seconds on the build server and produced no app files.
3. Ruled out: app settings, certificates and provisioning profile, since the build failed before using them.

## Solution
Request a fresh iOS build from AppCenter. A build that stops within seconds on the build server is usually a temporary build server failure and a new request goes through. If it fails again, check the new build log.
Root cause: temporary failure on the build server, not the app configuration.
