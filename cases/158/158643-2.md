## Debugging steps
1. Customer wanted to save a forum topic's content before removing it.
2. Pointed to the WordPress export tool, which lists forum content types.

## Solution
Go to WP Admin > Tools > Export and export Topics and Replies to save the content. Move the topic to Trash instead of deleting it permanently, so it can be restored if needed.
Root cause: How-to question; no dedicated per-topic export in the forum screens, the WordPress exporter covers it.
