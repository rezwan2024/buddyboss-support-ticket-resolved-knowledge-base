## Debugging steps
1. Checked the community pages (profiles, members, groups, news feed) and found they use the BuddyBoss ReadyLaunch layout, not the theme header.
2. Found the ReadyLaunch header menu was empty, so the original site menu items did not show.

## Solution
Logo: upload it under BuddyBoss > Settings > Appearance (ReadyLaunch) > Branding. Menu: go to Appearance > Menus, select the ReadyLaunch menu, add the original pages and links and save; the ReadyLaunch Menus settings also control the left sidebar items and custom links.
Slogan: Appearance > Customize > Site Identity > Tagline. Copyright: BuddyBoss Theme > Theme Options > Footer > Copyright Text.
Root cause: ReadyLaunch pages use their own branding and menu settings, which were not set up yet.
