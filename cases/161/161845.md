## Debugging steps
1. Customer runs several sites on Platform Pro and Theme 2.21.0 and wants to step through 3.0.x and 3.1.x on staging before going to 3.6.1.
2. Checked the account dashboard downloads: only recent versions (3.4.4 and later) are offered for Pro, the Theme and add-ons.
3. Checked the 3.x integration status for LearnDash, WP Fusion and ACF.

## Solution
Free BuddyBoss Platform: every older release, including 3.0.x and 3.1.x, can be downloaded from the official BuddyBoss Platform GitHub releases page. Older Platform Pro, Theme and add-on packages are not provided by support; only the versions in the account dashboard are available.
After updating Platform to 3.0 or later, enable the separate BuddyBoss LearnDash add-on from the BuddyBoss add-ons page so course features keep working.
WP Fusion and ACF have known compatibility issues on 3.x (fixes in progress), so test them closely on staging and hold the production update for sites that depend on them until the fixes are released.
Root cause: The dashboard release process only offers recent Pro, Theme and add-on versions, and 3.0 moved LearnDash out of the core into its own add-on.
