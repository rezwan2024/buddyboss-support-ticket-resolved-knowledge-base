## Debugging steps
1. Compared the failed push with an earlier delivered one: the earlier one only went to test devices on a test build, so it did not prove push worked in the live app.
2. Checked Dashboard > Users, Apps Installed column, to find members with a registered device.
3. Sent a manual push to a member with an iPhone registered: the push log showed "Delivery failed: Invalid APNs credential".
4. When creating the new key, Apple asked "this service must have environment type configured": Sandbox was selected, which only covers development builds.

## Solution
Create a new APNs auth key (.p8) in the Apple Developer account with Environment Production (or Sandbox & Production) and Key Restriction Team Scoped (All Topics), then upload the .p8 file and Key ID to the Firebase project.
Request a new iOS test build, send a manual push from BuddyBoss App > Push Notifications > Send New to confirm, then publish a new release build. The push log then showed Delivery confirmed.
Root cause: the APNs key connected to the app was invalid, so every iPhone delivery failed.
