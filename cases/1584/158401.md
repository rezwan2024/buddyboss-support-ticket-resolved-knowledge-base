## Debugging steps
1. Completed the same quiz on the website and in the app and compared the emails: the web email used the custom template with category scores, the app email used the LearnDash default subject and body.
2. Traced the app email sender with an SMTP log to the App plugin LearnDash quiz complete REST endpoint (QuizComplete.php).
3. Ruled out: LearnDash config. Admin and user notifications, quiz statistics and $categories in the Admin Notifications template were already set, and the web path used them correctly.
4. Escalated to the app developers, who confirmed the app quiz completion endpoint did not read the saved Quiz Email Settings.

## Solution
Update the BuddyBoss App plugin to v3.2.7 or later. App quiz completions then send the configured LearnDash quiz email with the custom subject and $categories.
Root cause: Bug in the App plugin quiz complete endpoint. It sent LearnDash's default notification instead of the saved Quiz Email Settings template and category data.
