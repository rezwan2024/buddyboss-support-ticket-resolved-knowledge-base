## Debugging steps
1. Tried to reproduce on a dev site and app with the latest plugins and the same quiz settings; could not reproduce at first.
2. Ruled out: quiz saving interval. The customer set quiz saving to 5 seconds and the issue stayed; the same steps worked on desktop web.
3. Ruled out: site plugins and settings. Reproduced on Android with the customer quiz and on a clean test site with a copy of the quiz settings: answer a few questions, leave the quiz with Prev, come back with Continue Quiz, finish.
4. Confirmed the site saves the answers and returns them to the app on resume, but the app Quiz Summary counts only the question where the quiz resumes and the ones answered after it.
5. Opening each earlier question again makes the count update, so Finish Quiz then works.

## Solution
Update to BuddyBoss App 3.2.6 or later and request a new app build. The app fix makes it count answers saved before leaving the quiz.
Workaround before updating: open each earlier question again before Finish Quiz, or finish the quiz in a web browser.
Root cause: an app bug in quiz progress handling. On resume the app ignored answers saved before the learner left the quiz.
