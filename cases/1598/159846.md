## Debugging steps
1. Checked the same photos on the website: descriptions show correctly there.
2. Reproduced in the live iOS build: descriptions show in some places (groups, gallery) and are missing in others (activity).
3. Ruled out: the app itself, as the same images showed descriptions correctly in a clean app setup.
4. Cleared the page cache plugin and the object cache on the server, then reopened the app: descriptions showed correctly in the gallery.

## Solution
Clear the BuddyBoss App API cache, the page cache plugin (for example LiteSpeed Cache) and the object cache on the site, then fully close and reopen the app. Clearing caches on the phone is not enough.
Partial fix: after clearing, the first multi-image activity showed all descriptions, but later activities still had some missing, so it may need repeat clearing or app team follow-up.
Root cause: stale activity data cached on the server was served to the app.
