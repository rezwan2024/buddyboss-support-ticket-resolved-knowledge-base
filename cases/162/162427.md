## Debugging steps
1. Confirmed Enable cover images for member profiles is on under BuddyBoss > Settings > Member Profiles > Profile Image.
2. Ruled out: settings toggle, Profile Headers and Profile Navigation settings, all set correctly.
3. Ruled out: profile template overrides in the child theme.
4. Opened the member change cover image page directly: the page loads but shows no upload form.
5. Checked the site layout: ReadyLaunch was active.

## Solution
Expected behavior, not a bug. ReadyLaunch uses its own simplified profile layout without cover images, so the cover image setting has no effect while it is active. To get member cover images, switch the layout under BuddyBoss > Settings > Appearance > Site Layout from ReadyLaunch to the BuddyBoss Theme / WordPress Theme layout. Otherwise cover images are not available with ReadyLaunch.
Root cause: ReadyLaunch does not support profile cover images by design.
