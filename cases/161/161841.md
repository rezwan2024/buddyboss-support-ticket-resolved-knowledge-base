## Debugging steps
1. Searched the bug tracker for a known report of the keyboard hiding the Save button on the Login Information screen. None found.
2. Tested the same flow on an Android test app (Next Gen, latest release): Profile > Account Settings > Login Information, typed a new password. The screen moved above the keyboard and Save stayed reachable.
3. Noted the customer's Android build was older than the current app release.
4. Asked for Classic or Next Gen, the Android version and the phone model, since keyboard resizing differs between Android versions, especially Android 15 and later.

## Solution
Generate a new Android build from the WordPress admin with the latest App plugin and have testers retry the same steps. Workaround: members change their password on the website under Account Settings > Login Information.
Root cause: likely an outdated app build. The latest release handles the keyboard correctly on this screen. Not confirmed by the customer.
