## Debugging steps
1. Customer asked if BuddyBoss supports PHP 8.5 and if PHP should update automatically to the newest version.
2. Checked: no official confirmation yet that BuddyBoss is fully tested on PHP 8.5.
3. For the PHP security patch, the fix depends on the patch release, not the main version. Minimum patched releases: 8.2.35, 8.3.36, 8.4.27, 8.5.12.

## Solution
On a live site, run a patched PHP 8.2, 8.3 or 8.4 release for now. PHP 8.3 or 8.4 is a good step up, so test it on a staging copy first. Ask the host to confirm the patch release and to restart PHP-FPM or Apache afterwards.
Allow automatic patch updates within the same version (for example 8.2.34 to 8.2.35). Do main version jumps (8.4 to 8.5) by hand after testing.
Root cause: PHP 8.5 is not yet confirmed as tested with BuddyBoss. The PHP security patch is applied on the server, not through WordPress or plugin updates.

## Customer note
Moved to PHP 8.4, said everything works and thanked the team.
