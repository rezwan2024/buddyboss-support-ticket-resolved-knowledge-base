## Debugging steps
1. Customer saw only "unknown error" on the failed iOS build in the BuddyBoss App dashboard.
2. Checked the iOS build log for the real error code: it showed E016 and E017, a signing certificate and provisioning profile problem.

## Solution
In the iOS signing settings, uncheck the option to generate certificate and provisioning profile, delete the existing signing certificate and provisioning profile with the cross sign, then check the generate option again and save changes. Send a new iOS build request.
Root cause: the stored iOS signing certificate and provisioning profile were invalid or out of date, so the build failed with a generic "unknown error".
