## Debugging steps
1. Checked the customer screenshot: a pasted long share link ran past the right edge of the post card on mobile, with the link preview card below it.
2. Reproduced on a clean BuddyBoss Theme test site at a 360 pixel wide screen with a similar long link.
3. Ruled out: the post body. A long link in the body wraps normally.
4. Found the overflow comes from the activity post title, which has no wrapping rule for long unbroken strings.

## Solution
Workaround until a theme fix ships: add this in Appearance > Customize > Additional CSS, publish, then clear the caching plugin cache and the browser cache.
```css
.activity-title, .activity-title h2 { overflow-wrap: break-word; word-break: break-word; }
```
Reported to the developers so the title gets the same wrapping as the body.
Root cause: the activity title in BuddyBoss Theme lacks overflow-wrap styling, so long links in it do not wrap.
