## Debugging steps
1. Courses migrated with the BuddyBoss Courses migrator show plain text instead of the Elementor design.
2. Ruled out: Elementor support for the course post type; enabling it in Elementor settings did not restore the design.
3. Confirmed Elementor keeps its layout in post meta tied to the original post ID, and the migrator creates new course posts without that meta.

## Solution
Expected behaviour, not a migrator bug. Per course: open the original page in Elementor, folder icon in the bottom bar, Save as Template; open the migrated course in Elementor, folder icon, import the template from My Templates; then run Elementor > Tools > Regenerate CSS & Data.
For many courses, a one-off script that copies the Elementor meta from the old post IDs to the new course IDs is faster.
Root cause: the migrator copies post content only, and the Elementor layout lives in post meta of the original post.
