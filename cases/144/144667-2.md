## Debugging steps
1. Images broke on the registration page and other areas right after enabling Offload Media with Cloudflare.
2. Inspected a broken image in the browser: the image source ends with /public, the Cloudflare Images variant name.
3. Ruled out: offload settings, the variant named public did not exist in the Cloudflare account.

## Solution
In the Cloudflare Dashboard, go to Images, Variants and create a variant named public (set to Always public). Inspect other broken images and create any other variant name they use at the end of the URL.
Root cause: Offload Media serves Cloudflare Images with the /public variant, which was missing in the Cloudflare account.
