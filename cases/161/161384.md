## Debugging steps
1. Read the PHP error log: fatal error in BbmsOrderQuoteBuilder basket_fingerprint() while the Stripe payment form loads, before any request reaches Stripe.
2. Ruled out: PHP version (same on PHP 8.3 and 8.5), tax settings, user role, plan type (monthly and yearly both fail) and other plugins.
3. Ruled out: reinstall, rollback to 1.14.0 and 1.14.2 beta, since the class file is missing from the release package in all of them.
4. Confirmed as a known packaging bug: the code calls the class but the file that defines it was left out of the release.
5. Ruled out: 1.14.2, which still failed because the calls in BbmsOrderQuoteBuilder were not guarded.

## Solution
Update BuddyBoss Membership to 1.14.3 or later, then click Connect with Stripe again under Memberships > Settings > Payments and run a test checkout in Stripe test mode.
No settings workaround exists on 1.14.1 or 1.14.2, because the failing code runs before the tax options are checked.
Root cause: the BbmsStripeTaxIntegration class file was missing from the Membership release package and the calls to it were not guarded; 1.14.3 guards the calls when Stripe Tax is off.

## Customer note
Said paid checkout works on 1.14.3 and thanked the team, but noted the class file is still missing, so sites with Stripe Tax enabled may still hit the error.
