## Debugging steps
1. Reproduced on a clean BuddyBoss install: posting an activity update with an @mention works, so it is site specific and not a platform bug.
2. Noted the message is generic and shows whenever the activity save request fails for any reason.
3. Asked whether the same text posts without the @mention, and whether it fails for every mentioned member or only some.
4. Asked for the browser Network tab status code (403, 500) and response of the failing request, plus the Console tab, and current WordPress, Platform, Platform Pro, Theme and PHP versions.
5. Suggested ruling out security plugins and firewalls (Wordfence, Sucuri, Cloudflare, server ModSecurity) that can block requests containing the @ character, by disabling them and retesting.

## Solution
No change was needed: the error stopped on its own and posting with @mentions worked again. If it comes back, check the failing request status code in the Network tab and test with security plugins or firewall rules disabled.
Root cause: unknown, a temporary failure of the activity save request on the site.

## Customer note
Thanked the team for the fast response and said it was a temporary error because it suddenly started working.
