## Debugging steps
1. Reproduced from the customer video: in the app Edit Profile screen, select box fields (such as a state field) show no current value and ask for a selection.
2. Asked the customer to update the BuddyBoss App plugin and BuddyBoss Platform plugin to the latest versions.
3. Asked for a new app build made after the 3.2.0 release (21 September) and uploaded to the stores.
4. Customer retested on the new release.

## Solution
Update the BuddyBoss App plugin and BuddyBoss Platform to the latest versions, then create a new app build (app version 3.2.0 or later) and submit it to Apple and Google. After the new release, select fields show their saved value in Edit Profile.
Root cause: Next Gen app rendering of select profile fields in Edit Profile, resolved in the app version 3.2.0 release.

## Customer note
Confirmed both reported issues were resolved in the new app release and asked to close the ticket.
