## Debugging steps
1. Reproduced the Tutor LMS frontend dashboard display problem with BuddyBoss Theme active after the latest updates.
2. Matched it to a known BuddyBoss Theme bug with Tutor LMS and escalated it to the developers.
3. The fix went through development, code review and QA, then was released.

## Solution
Update BuddyBoss Theme to version 2.22.4 or later, which fixes the Tutor LMS dashboard display.
Root cause: A BuddyBoss Theme bug broke the Tutor LMS dashboard layout after recent updates. It was fixed in Theme 2.22.4.
