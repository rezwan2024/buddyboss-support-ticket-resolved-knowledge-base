## Debugging steps
1. Read the fatal error stack trace: it points to BuddyBoss\Sharing\Modules\Plugin_Compatibility->disable_yoast_seo() at line 134.
2. Confirmed Yoast SEO 28.7 removed the deprecated WPSEO_Frontend class, while Sharing 2.0.3 calls WPSEO_Frontend::get_instance() without checking that it exists.
3. Matched it to a known Sharing bug and reported it to the development team.

## Solution
Update BuddyBoss Sharing to v2.1.2 or later. Until then, a small MU-plugin bridge or this edit in includes/Modules/Plugin_Compatibility.php (around line 134) stops the fatal error (workaround, replaced by the next Sharing update):
```php
// Replace: $frontend = \WPSEO_Frontend::get_instance();
$frontend = is_callable( array( '\WPSEO_Frontend', 'get_instance' ) ) ? \WPSEO_Frontend::get_instance() : null;
```
Root cause: Sharing called the WPSEO_Frontend class directly, and Yoast SEO 28.7 removed that class.
