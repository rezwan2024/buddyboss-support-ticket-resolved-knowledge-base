## Debugging steps
1. Customer reported that the Members content type of Network Search builds part of its query from the search term without escaping, before the query is prepared.
2. The report was tested only by calling the Members search query method directly in PHP and reading the generated query through a filter, on a private local install.
3. Asked for a full report, since the email arrived cut off, and for one raw logged-out AJAX search request and response that shows the value reaching the run query.
4. Noted the site ran Platform 3.0.4 while 3.4.3 was current, and asked for a retest on the current version. Passed the report to the development team and moved it to a restricted channel.

## Solution
No fix was confirmed in the ticket. Workaround the customer used: Settings > Search > Network Search, turn off the Members content type so the Members search does not load at all.
Next steps: update BuddyBoss Platform to the current version and retest. The development team checks the current code path.
Root cause: reported as the Members search term being added to the query without escaping in Platform 3.0.4. Not confirmed through a real request in the ticket.

## Customer note
No reply after the agent asked for the full report and a request capture. Ticket closed for inactivity.
