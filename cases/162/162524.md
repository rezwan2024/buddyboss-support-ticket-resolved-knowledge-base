## Debugging steps
1. Read the error log: the fatal came from the theme menu icons code (Menu_Icons_Front_End::init) while the header nav menu was rendering.
2. Logged in with the temporary admin account and checked the dashboard, Plugins, Themes and homepage.
3. Ruled out: a lasting break. All pages loaded normally with Platform 3.6.2, Platform Pro 3.3.4 and the BuddyBoss child theme active.

## Solution
No change was needed. The error was a one-time fatal from the site being visited while the theme files were still being replaced during the update, and the site loaded normally afterwards. If it keeps failing, replace the buddyboss-theme folder with a fresh copy of the latest theme.
Root cause: the header menu loaded while the theme update was only partly done, so the menu icons class was not available yet.
