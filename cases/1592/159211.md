## Debugging steps
1. Noted the navigation and profile icon vanished only on mobile and in several sections at once, which points to the shared header or page layout, not each feature.
2. Checked the site as a logged-in member on a mobile browser.
3. Found the ReadyLaunch Course Template was not enabled under Template Pages, so course pages did not get the ReadyLaunch header.

## Solution
Enable BuddyBoss > Settings > Appearance > General > Template Pages > Course Template, then clear the page cache (for example WP Rocket). The header, hamburger menu and profile icon then show on mobile.
After that, the course template overrode some custom fonts and background colors. The customer fixed this on their own by dequeuing the conflicting scripts.
Root cause: Course pages were not using the ReadyLaunch course template, so the ReadyLaunch mobile header was missing on them.

## Customer note
Reported that custom fonts and colors were overridden after the change, then said they solved it by dequeuing scripts.
