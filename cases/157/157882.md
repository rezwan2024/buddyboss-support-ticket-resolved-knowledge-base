## Debugging steps
1. Ruled out: browser and session, logging out and in and using another browser did not change anything.
2. Agent could not reach the site, all login pages returned 403 Forbidden because the site has a country restriction.
3. Allowing the agent's IP and country let the agent in, but builds still failed because the App Center server is a separate server.
4. Development team found the App Center server could not download the app translation pack from /wp-content/uploads/bbapp/ or post build status to /wp-admin/admin-ajax.php, so the build request failed.
5. Updated the BuddyBoss App plugin to the latest version, which now shows an alert with the exact reason when a build request fails.

## Solution
Add a firewall/WAF and security plugin exception, placed before any country restriction, that allows requests with a user agent containing BuddyBossBot and access to /wp-content/uploads/bbapp/ and /wp-admin/admin-ajax.php (action=app_center_api). On Cloudflare Pro/Business, create a top custom rule `(http.user_agent contains "BuddyBossBot")` with action Skip for bot fight, browser integrity, security level, rate limiting and managed rules; on the Free plan turn off Bot Fight Mode while the build runs. Then send a new build request.
Root cause: the site firewall and region restriction blocked server-to-server requests from App Center, so the build request failed silently.

## Customer note
Said the build is working now and thanked the team.
