## Debugging steps
1. Confirmed Group Types and Auto Membership Approval were enabled in BuddyBoss > Settings > Social Groups.
2. Confirmed the group type existed and had Profile Type Joining set to All Profile Types.
3. Ruled out: Screen Options and a sidebar Group Type box, they belong to the older group edit screen and do not exist in the current Edit Group window.
4. Checked the group type settings and found its Visibility was set to Private, and the group types list showed 0 groups for it.

## Solution
Edit the group type, change its Visibility from Private to Public and click Update. Then open the private group in All Groups, select the group type in the now visible Group Type option and save; the group types list should show 1 group. Test Request Access with a normal member account, not an admin.
Group type visibility does not change the group privacy: the group stays Private with members-only content, and approval works the same in the BuddyBoss App.
Root cause: a group type with Visibility set to Private cannot be selected anywhere, so the Group Type field does not appear on the group edit or create screens.
