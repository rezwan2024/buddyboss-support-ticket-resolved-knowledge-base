## Debugging steps
1. Error appeared on Send Build Request, when the build server downloads the app translation file (languages-flutter JSON) from the site.
2. Checked access with an administrator account to reproduce the error on the BuddyBoss App build screens.
3. Ruled out: Cloudflare; the WAF skip rule for BuddyBossBot was active and the build server got through Cloudflare to the site.
4. Requesting the file with the user agent "BuddyBossBot/1.0 BuddyBoss Bot" returned 400 Bad Request from the host, while a normal browser user agent worked.

## Solution
Ask the hosting provider to allow the user agent "BuddyBossBot/1.0 BuddyBoss Bot" for the site, then send a new Next Gen build request. This cannot be fixed from WordPress or Cloudflare.
Root cause: a hosting provider server rule rejected all requests from the BuddyBoss build server user agent with 400 Bad Request.
