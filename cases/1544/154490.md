## Debugging steps
1. Confirmed the custom wording works on the website but not in the app.
2. Ruled out: missing translation files. Loco Translate only covers Platform and Theme strings on the website, the app's native screens use their own string set.
3. Checked BuddyBoss App > Translations, where native app strings can be searched by text or by Source Text ID.

## Solution
Set the wording in BuddyBoss App > Translations: search the string, type the new text in the Translation field (works with the English language selected, for rewording English), Save Changes, then force close and reopen the app.
If the wording still does not show in a test or custom build, create a new app build and install it.
Root cause: Loco Translate files do not apply to the native app interface, which uses the BuddyBoss App Translations panel.
