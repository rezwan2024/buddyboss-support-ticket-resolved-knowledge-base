## Debugging steps
1. Confirmed the labels show in English on the front end for members, not only in the admin settings, and the filters were never reordered or toggled.
2. Noticed "All Updates" was translated while the other filter labels were not, so the translation file was not missing as a whole.
3. Found the labels are defined in BuddyBoss Platform (bp-core/bp-core-options.php, bb_get_activity_filter_options_labels and bb_get_activity_sorting_options_labels) under the buddyboss text domain.
4. Ruled out: missing strings in code. The bundled buddyboss.pot has all of them, but the bundled French .po file is older than these labels and has no entries for most of the filter and sorting labels.
5. Ruled out: Loco Translate search alone. Loco only lists strings already in the .po file, so the new labels do not show until the file is synced.

## Solution
In Loco Translate, go to Plugins, BuddyBoss Platform, open the French language, click Sync to pull the current strings from buddyboss.pot, then search each label, enter the French text and save. Set Site Language to French and check the activity feed on the front end.
Save the file to Loco's System location (wp-content/languages/plugins) so a Platform update does not overwrite it. The labels in wp-admin under Settings, Activity may still show in English.
Root cause: the French translation file bundled with Platform was older than the Activity Feed filter labels, so they had no French entries.
