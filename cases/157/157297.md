## Debugging steps
1. Customer translated all Achievements and Ranks strings in WPML String Translation; the user menu items did not change, while Timeline, Connections and Invites did.
2. Explained that Achievements and Ranks menu labels come from GamiPress Achievement Types and Rank Types (custom post types), not from plain translation strings.
3. Customer set those post types to Translatable and translated them into the site language; the menu items still stayed in English.
4. Ruled out: outdated plugins. Updating Platform, Platform Pro, GamiPress, WPML, the WPML BuddyPress/BuddyBoss add-on and the theme to the latest versions did not change it.
5. Site access was requested to check further; the customer did not reply.

## Solution
No working fix was confirmed. Suggested steps: in WPML > Settings > Post Types Translation set GamiPress Achievement Types and Rank Types to Translatable, translate each type in WPML Translation Management, then clear all caches. This did not change the menu on the customer's site.
Root cause: not found; the Achievements and Ranks profile menu labels come from GamiPress post type labels and are not picked up by WPML String Translation.

## Customer note
Said the menu items were still unchanged after updating everything and asked for further suggestions; no reply after site access was requested.
