## Debugging steps
1. Checked BuddyBoss App settings and LearnDash quiz settings: no option controls the highlight.
2. Ruled out: plugin conflict. A staging test app with only BuddyBoss, MemberPress and LearnDash still showed the highlight.
3. Reproduced the same yellow highlight on clean dev apps on both iOS and Android.
4. Confirmed with the product team that this is the default quiz interface of the Next Gen app, present from the first test mode install, not a recent change.

## Solution
No fix. This is expected default behavior of the Next Gen app quiz interface, and there is currently no setting in the app or LearnDash to disable it. Tell the customer nothing on their site causes it and log a request to remove it or make it optional as product feedback.

Root cause: the Next Gen app quiz interface highlights quiz answers in yellow by design.
